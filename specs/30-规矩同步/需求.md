# 规矩与 skill 同步到各机各家 AI，旧仓工具箱退役（#30）

对应计划：plan.md P6 的「规则」一条。
设计依据：design 第三节第 16 条。各家 AI 读全局规矩的位置，映射表写在同步脚本里。

## 要什么

- `AGENTS.md` 上半段是所有仓通用的一段（创始人已逐条过目定稿），下半段只管本仓。
- 同步脚本：
  - `--apply`：把通用段写进各家 AI 的全局入口，只改受管的那一块，首次接管先备份；把 `agents/skills` 下的 skill 分发到各家的 skill 目录，只动本脚本装的。
  - `--check`：逐家报一致 / 漂移 / 缺失 / 没装 / 没查成，退出码分三态。
  - `--retire-old`：撤掉指向旧仓的 skill 链接和两个旧子代理。
  - 法国三个用户（两个会话用户和 pilot）接进 france.sh。
- 方法类 skill 改成通用版，放 `agents/skills`（PR #27）。
- 本机切换：废掉旧仓的开会话自愈 → `--apply` → `--retire-old` → `--check` 全绿 → 在 fleet-dao 目录开新会话接手。

## 怎么算做完

- 两个 PR 审过合进 main。
- 法国三个用户 `--check` 全绿，第二遍零改动。
- 本机切换后 `--check` 全绿；新会话在 fleet-dao 目录起得来，旧仓的钩子不再触发。
