# pilot 上装 Linux 版 reclaude-mirasim 启动器，Mirasim 远程能用 Claude（#33）

对应计划：plan.md P0「WireGuard」
设计依据：ops 第五节「reclaude-mirasim 启动器」

原话：未来本机想用 Mirasim ssh 连法国（创始人 2026-09-25）。

## 要什么

- pilot 家目录下装 Linux 版 reclaude-mirasim 启动器（现在的 Windows 版在旧网关仓里）；装好之前 Mirasim 远程里别选 Claude——不装的话 Mirasim 会把自己网关的地址塞进 reclaude，reclaude 回 `non_cc_client` 并上报，攒多了设备会被解绑（这个口子已记在 ops 第五节）。
- 启动器代码从旧网关仓（ai-gateway-stack）搬进本仓 `deploy/`，跟着这个仓一起维护，不再挂靠旧仓。

## 怎么算做完（issue 里没写验收，本处按「要什么」补写）

- pilot 的 `~/.local/bin` 下能找到这个启动器，装机读回能查到它在、版本对；装第二遍零改动。
- 用它起一个 Mirasim 远程的 Claude 会话，reclaude 不报 `non_cc_client`。
