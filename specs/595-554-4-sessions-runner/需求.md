## 场景

554-1 把「起一次无头会话、喂一份交代、干完退出、记一笔」做成可调用的接口（`packages/engine/src/runner/`、`packages/engine/src/segments/`），但**没有接到任何调用方**——sessions.ts 还在用 Fusion 的链路，runs 是 NotWired 占位。

本切片把 runner 接到会话起的链路里：会话要起的时候，如果 brief 标记是「三段之一」（对题 / 动手 / 验收），就走 runner/one-shot 起无头进程；否则照旧走 Fusion 的链路。**Fusion 的调度（`packages/engine/src/workflows/{fusion,requirement,subtask,merge-queue}.ts`）完全不受影响**。

这是 554-2（测试移出会话）、554-3（分档挑档，已合 #590）、555（验收实做）、556（真 runs 表）之间的**骨架切片**：把插头挂上，但不动三段各自的业务实做。

## 怎么算做完

1. **SessionBrief 加可选 `segment: SegmentLaunch`**：`{ kind: 'scope' } | { kind: 'manual'; branch; baseSha } | { kind: 'verify'; prNumber; baseSha; headSha; changedFiles; diffText }`——给了就走 runner，没给就走 Fusion 原链路。
2. **`real/prompts.ts` 加 `segmentBriefFrom`**：把 SessionBrief 转成 runner/one-shot 的 `AnyBrief`（zod 钉过）；形状不对当场抛，不鲁式化。
3. **`real/sessions-segment.ts` 新增 `launchSegment`**：调 `runOneShot`，拿 OneShotResult + verdict。Spawner / buildCommand / runs 依赖注入；没装当场 `SEGMENT_NOT_WIRED`。
4. **`real/sessions.ts` 的 `startSession`** 加 if branch：`brief.segment` 给了 → launchSegment 起、登记到 `segments: Map<runId, Promise<SegmentOutcome>>`、立即返回 `StartSessionResult { sessionId: runId, resumed: false }`；没给 → 走原 `launch()`。**`awaitSession`** 先查 segments map，查到等 promise、把 `SegmentOutcome` 折成 `SessionEnd`；查不到走原链路。**'`reapOrphanSessions` / `stopSession` / drain / Jev / 卫生检查都不变**。
5. **测试** `packages/engine/test/real/session-segment.test.ts`：
   - fake spawner 起会话走通三段（scoping / manual / verify 各一），拿 stdout、verdict ok，NotWired JSONL 落一行。
   - **故意造红**：blank stdout（不许拿空当跑完）/ exit=1 / verdictLine 又 pass 又 fail——verdict 必须明确 failed，写明哪一条。
   - NotWired 写入：verify 一段跑完时，`_tmp/runs-not-wired/<日期>.jsonl` 出现一行，带 runId / segment / model / startedAt / endedAt / outcome；缺一项都不写（zod 已经挡）。
   - 依赖没装（spawner / buildCommand / runs 缺任何一个）：当场 `SEGMENT_NOT_WIRED`，不落 runs。
   - brief.segment 没给：launchSegment 当场 BAD_INPUT（不会被误调）。
6. **测试全绿**：`pnpm exec vitest run packages/engine/test/real/session-segment.test.ts` 全过；`pnpm exec vitest run packages/engine/test/runner/ packages/engine/test/real/prompts.test.ts` 不回归。
