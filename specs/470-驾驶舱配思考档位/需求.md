# 驾驶舱能按模型配会话的思考档位，默认 high（#470）

对应计划：未排期
设计依据：design 第四节「架构」（法国库里的路由配置）

原话（创始人 2026-09-28 傍晚）：「我发现你现在grok测试开的是xhigh，我建议都开需求都开medium或者high档；驾驶舱后续可配置档位；默认high怎么样」。AI 理解：各家模型干活的会话思考档位默认 high、简单活可以 medium，不用 xhigh；以后在驾驶舱里按模型配档位，现在先记单、未排期。

## 起因

帅位同意了默认 high（决定记在 specs/169-Fusion形态/需求.md）。现在帅位起的别家模型会话由启动器 `worker.mjs --effort` 定（默认 high），引擎的会话由各自路由里写的档位定，两处各管各的，驾驶舱里看不到也改不了。

## 要什么

- 驾驶舱里按项目、按模型（路由）配思考档位（low / medium / high / xhigh），默认 high。
- 改了走「先改仓库再部署」：驾驶舱改完开 PR 自动合，不在机器上手改。
- 启动器和引擎从同一处读档位。

## 怎么算做完

- 驾驶舱改一个模型的档位，下一个起的会话命令行里带的就是新档位（有测试）。
- 没配的用 high；配置读不到或写错就报错、不起会话，不静默当 high 用（配一条故意造出失败的测试）。
