# 演示版：方案（#29）

需求见同目录 `需求.md`。一个 PR 做完，按下面五块拆，先后就是这个顺序（后一块用前一块的东西）。

## 1. 可见范围：约定与后端

- 约定（`packages/shared/src/web-api.ts`）：九个模块（看板含总览、任务详情含清单、调度台、渠道与账号、额度、定时任务、通知、操作记录、设置），三级细节（`status` 只看状态和耗时，标题换成编号；`titles` 能看标题；`process` 能看步骤和过程），有效期。范围文件只放这三样：拿到链接的人都读得到它。什么都读不到时的内置范围最严：只看看板、只看状态和耗时。
- 后端（`packages/api/src/demo.ts`）：发布处是法国本机一个目录（`FLEET_DEMO_DIR`）。`scopes/<口令的 SHA-256>.json` 一条链接一份，`scopes/default.json` 是默认范围；备注、创建人在 `links/`，只留本机。口令 32 字节随机数，只在新建时回一次，后端只存哈希。作废 = 删文件；到期的每小时撤一次，列表时也顺手撤。四个接口先记操作记录再动手。
- 演示版的地址不归后端管：发布脚本构建驾驶舱时写进前端（`FLEET_DEMO_URL`），链接由前端拼。

## 2. 可见范围推到香港

法国 root 的 `fleet-demo-scopes`（`deploy/france/`，france.sh 装）：范围目录一变就推（path 单元），每 10 分钟补一次（timer），用发静态文件那把上传钥匙推到香港 `<演示版路径>scopes/`，`--delete` 让作废当场生效。目录归 fleet，root 只当数据读：文件名、大小、内容都得和后端写的一模一样才推（认不出的不推、退出 1），借符号链接带不出本机文件。

## 3. 演示版：同一份前端另打一个包

- 品牌：代码里统一 `import { brand } from '#brand'`，正式构建是 `src/brand/cockpit.tsx`，演示版构建换成 `demo.tsx`（名字「子午 · 控制台」、新图标；中转站、判断题、AI 调度员这类通用说法；不给仓库外链）。演示版的路由表里没有登录页、占位页和发链接的页；取数据的实现在构建时定死，连后端的那份代码进不了演示版的包。
- 运行时（`src/demo/`）：先读范围再出页面——`?k=` 或 `#k=` 的口令算 SHA-256，读链接的范围，过期、作废（404 或门面回落成网页）、读坏了就退回默认范围并在横幅上写明原因，默认范围也没有就用内置的。没开放的模块：导航、⌘K、铃铛、总览面板里都不出现，直接打开就是「没开放」页，数据层也回 `demo_hidden`。细节按级别在交给页面之前就收起。按钮照样能点，改的只是浏览器里的假数据。
- 假数据换成一个虚构网店「orbit」的活，不再照抄本项目的路线图。

## 4. 打包与扫描

`packages/web/scripts/demo.ts build`：不带源码对照文件、去掉全部注释，契约里绕不开的执行方式编号 `mirasim` 换成 `relay`；打包完扫产物（`src/build/scan.ts`），出现真名、内部叫法、GitHub 地址、创始人的 GitHub 用户名、源码对照文件，或发布时从服务器配置传进来的词（`FLEET_DEMO_FORBID`，发布脚本传真域名），就打包失败；一个文件都没扫到也算失败。扫描的名单自己写一份，不读品牌文件。CI 每个 PR 打一次。

注释去掉了，第三方库的许可证声明另落一个文件：产物根上的 `licenses.txt`，只有库名、版本、许可证和许可证原文，页面上不放链接。汇总用 vite 自带的 `build.license`；`src/build/licenses.ts` 补它认不出的（Tailwind 这类在样式表里按包名引进来的库），把指向代码托管网站的链接换成占位（扫描照样扫这个文件），认不出许可证的库让打包失败。演示版打包完先查这个文件在不在，缺了就失败。

## 5. 发布

- `deploy/release.sh`：`FLEET_HK_PARTS` 多一样 `demo`，演示版发到 `FLEET_DEMO_PATH`、只动那一个目录、不删 `scopes/`；`web`（正式驾驶舱发到根地址）照旧默认不发，而且整套换根地址时也不碰演示版的目录。健康检查看演示版首页是不是这一版、深链接回落到哪。
- `deploy/hk.sh` 与两份 nginx 模板：演示版单有一段（深链接回落到它自己的首页、首页不缓存、`scopes/` 查不到就 404 且不缓存）；路径是 `hk.env` 的 `FLEET_DEMO_PATH`，和法国写同一个。
- 顺带（审官跟进的一条）：调度台、换模型对话框按路由判额度（`routeQuotaHeadline`，判法用 shared 的 `windowAppliesTo`）；按池说的地方写「fable 组已用满」。
