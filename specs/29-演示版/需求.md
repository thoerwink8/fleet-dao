# 演示版单独放：游客可见范围由正式版控制、换皮（#29）

对应计划：plan.md P2 驾驶舱 v1。
设计依据：design 第十四节「驾驶舱：飞书账号登录」下「演示版」及其几小条。
2026-09-25 改：下面「换皮」一条作废——演示版和正式驾驶舱长得一模一样、只换数据，两边都不出现仓名（见 #54）。

## 要什么

- 假数据的演示版放在 `/demo/`，不用登录，页面顶上写明「演示版·全是假数据，操作不会有任何影响」；正式驾驶舱的登录页上有「看演示版」入口。
- 游客能看什么由正式版控制：演示链接带模块开关、细节看到哪一级、有效期，随时作废；不带链接打开按默认范围，默认从严。范围由后端发布成香港上的静态文件，演示版只读它，法国停了照样能看。
- 换皮，不让人顺藤摸瓜找到项目：不相关的名字和图标、内部叫法换成通用说法、仓名和项目名全用假的、不带 GitHub 链接、打包不带源码对照文件、去掉包名和注释；打包后扫产物，出现真名、真域名、github.com 地址、创始人的 GitHub 用户名就打包失败。
- 演示版放在哪个域名、哪个路径都走配置（以后搬到名字不沾边的新域名）。
- 发布脚本能分别发演示版和正式版；正式版发到根地址默认不发，打开前先告诉创始人。

## 怎么算做完

- PR 审过合进 main；打包扫描有先红后绿的用例。
- 香港真发一次 `/demo/`：关掉一个模块、作废一条链接都当场生效；根地址上现在的演示版没被动。
