# Fleet2 会话页换成对话界面（#3918）

- 状态：在做（2026-11-13）
- 起因：创始人看了本机会话页，嫌左栏是一排裸表单、标题是会话号、预览看不懂、内部事件占了大卡片、底下四个平按钮。
- 来源：参考了 mirasim 的分层思路（左列表、中对话、底下一个发送或停止、右栏看改动）和它的 token 分组（文字五档、层级、区域、状态）。DeepSeek 网页的空状态是没会话时居中一个大输入。cc-haha（https://github.com/NanmiCoder/cc-haha ，Community Source，代码不进本仓）只看了 README 里的工作台截图和桌面端目录名：多会话、开工可选 worktree、右栏按文件看 diff、输入框里选模型。代码全部自写，或来自 MIT 的 Radix 与 shadcn/ui 的写法。没有从 mirasim 或 cc-haha 拷代码、样式、色值或 class。前缀用本仓的 `--fleet-*`，不用别人的前缀。

## 布局

- 左栏：搜索和「+」（新会话、添加工作区）。会话按置顶、最近、工作区分组。一行是标题（第一句，不显示 id）、最后一句可读预览、模型、轮数、运行中的点。
- 中间：人的话靠右，模型的话是正文，读文件和改动收成可折叠的一行。会话建立、轮次开始这类内部事件只在「调试」里。
- 底部：一个输入框。空闲时圆钮发送，运行中变成停止。运行中再写的话进排队条，条上有引导、插队、撤回。框下是工作区、模型和是否另开了工作树。
- 右侧：可收起的改动。
- 没选会话：居中的新会话，选工作区、agent、模型和档位。
- 任务页的批次选择和视图切换用同一套组件。香港 `/next/` 仍是原来的事件流，e2e 走那一条。

## 组件和令牌

组件在 `packages/harness-web/src/ui/`：按钮、输入、多行输入、徽章、对话框、下拉、折叠、提示、滚动区、分隔线。批次切换保留原生 select（e2e 要用 `selectOption`），样式包在 `NativeSelect` 里。页面不再写裸的 select 和 button。`chip.tsx` 转出 `Badge`。

颜色、字号、圆角、间距只在 `src/app.css`。浅色沿用这份里原有的值。深色是同一套名字加深。fg-4、fg-5 是在原有两级灰之间补的两档。运行中的点用 `running`，和 `ok` 同一个绿，不另做装饰绿。旧工具类（`bg-canvas`、`bg-surface`、`text-ink`）还在，指向上面的语义层，香港那份页面不用改 class。

### token 对照

他们的分组在左，我们的变量在右。色值不抄，所以表里不写别人的具体颜色。他们文字的第一档没有数字后缀，我们收成 `fg-1` 到 `fg-5`。他们还有 `fg-6`、`fg-faint` 和各种 glow，这次不用。

| 分组 | 他们的名字 | 我们的变量 | 工具类 | 现在用在 |
|---|---|---|---|---|
| 文字 | fg、fg-2…fg-5 | `--fleet-fg-1` … `--fleet-fg-5` | `text-fg-1` … `text-fg-5` | 正文、次文字、说明、更弱的两档。旧名 `ink` / `ink-2` / `muted` 指前三档 |
| 层级 | surface | `--fleet-layer-surface` | `bg-canvas` | 页面底 |
| 层级 | raised | `--fleet-layer-raised` | `bg-raised`、旧名 `bg-surface` | 抬起的白卡片 |
| 层级 | panel | `--fleet-layer-panel` | `bg-panel` | 右栏改动 |
| 层级 | inset | `--fleet-layer-inset` | `bg-inset`、旧名 `bg-subtle` | 凹进去的输入井、行悬停 |
| 层级 | control | `--fleet-layer-control` | `bg-control`、旧名 `bg-neutral-soft` | 控件底 |
| 层级 | edge | `--fleet-layer-edge` | `border-edge`、旧名 `border-line` | 发丝线 |
| 层级 | selected | `--fleet-layer-selected` | `bg-selected`、旧名 `bg-brand-soft` | 选中行、人的气泡底 |
| 区域 | sidebar / header / rail | `--fleet-region-sidebar` 等 | `bg-sidebar`、`bg-header`、`bg-rail` | 侧栏、顶栏、窄轨。侧栏和顶栏跟 raised 同一色 |
| 区域 | modal / overlay / dropdown / card | `--fleet-region-modal` 等 | `bg-modal`、`bg-overlay`、`bg-dropdown`、`bg-card` | 对话框、遮罩、下拉 |
| 状态 | ok / warn / err / info | `--fleet-ok` 等 | `text-ok`、`text-warn`、`text-err`、`text-info` | 旧名 success / warning / danger / brand |
| 状态 | running / idle | `--fleet-running`、`--fleet-idle` | `bg-running`、`bg-idle` | 会话行上的点。running 与 ok 同色 |
| 状态 | act / badge | `--fleet-act`、`--fleet-badge` | `bg-act`、`bg-badge` | 主操作、小标底。旧名 brand、brand-soft |
| 部件 | composer / bubble / menu | `--fleet-composer`、`--fleet-bubble`、`--fleet-menu` | `bg-composer`、`bg-bubble`、`bg-menu` | 底部输入、人的气泡、菜单 |
| 动效 | （他们有时长和缓动） | `--fleet-dur-fast` 120ms、`--fleet-dur` 150ms、`--fleet-ease` | 变量，不另造一套动画库 | 已有的淡入仍是 150ms |
| 圆角 | （他们有 radius） | `--radius-sm/md/lg` 4/8/12 | `rounded-sm` 等 | 和原来一样 |

重件这次不进页面：代码 diff 仍是文本，不接 Monaco；没有终端，不接 xterm；正文用自己的围栏分段，不接 tiptap、remark、katex。图标继续用 lucide，等宽继续用 JetBrains Mono。组件交互继续用 Radix（MIT）。
