## 要干成什么：三段里的第三段——合之前一次冷调用，判「这活是不是真的做完了」。

## 为什么现在做：创始人 2026-10-02 问「审官需不需要」。**需要，但它不是岗位、不是常驻、不是一段流水线——就是合之前那一次调用。**

## 怎么算做完：
1. **喂三样**：diff + 单子的「要什么」+「怎么算做完」。只喂 diff 查不出「单子说要 A、代码写了 B」。
2. **换一个跟主力不同的家族**（或至少换个新会话）。依据：自审会把准确率从 95.5% 拉低到 89.0%。
3. **只有三种能挡**：没做到验收条 / 有证据弄坏原有功能 / 安全或丢数据。默认 1 轮、最多 2 轮。
4. **读不到 PR 必填栏就明确失败**，不许拿「读不到」当「没问题」（通用段底线第三条）。
5. 不造「交接条」这个物件：单子存「要什么」，PR 正文存「做了什么」，验收**现读**。
