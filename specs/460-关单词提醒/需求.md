# 「做完就关单」填了是却没写关单词：检查页提醒、每天对账捞出来（#460）

对应计划：v1 Fusion 接活
设计依据：design 第五节「合并闸」、第七节「关单要有结果」

原话：无（#457 第二意见的「小毛病」，帅位 2026-09-28 收下开单）。

AI 理解：#444 起合并闸不再查「写了关单就要带结果文档」，也不再拦「这个 PR 做完就关单」填了「是」却没写关单词（`Closes #<号>`）的 PR。这种 PR 合进去以后 GitHub 不关单，单子一直开着，每天的关单对账也捞不到（它要么看已经关了的单、要么看已有的结果文档）。

## 要什么
- PR 检查页的必填栏提醒（`packages/conventions/src/pr-fields.ts`，只提醒、不挡合并）加一条：「这个 PR 做完就关单」填了「是」、正文却没有关单词时，提醒写明要补哪一行。
- 每天的关单对账加一种：合并了的 PR 填了「是」、挂的那张单还开着，列进日报（写明 PR 号和单号），由后台照规矩补关或提醒补结果。

## 怎么算做完
- 故意造出的失败，每条一个测试：填「是」没写关单词 → 检查页有这条提醒、合并闸照样判绿；合并后单还开着 → 对账列出这张单。
