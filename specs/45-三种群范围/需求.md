# 三种群各管各的范围，开群靠点按钮：总控群开项目群、项目群开讨论群（#45）

对应计划：plan.md P4「需求拍板期与需求讨论群」
设计依据：design 15.4「三种群各管什么」

起因：创始人 2026-09-25：「我在总控群 @ 机器人有什么意义？能不能让总控群、项目群和需求讨论群里 @ 机器人更有意义。」「需求讨论群也按需开；不要文字形式开，总群开项目群、项目群开需求讨论群，手动点击开。」

拍板（2026-09-25）：
1. 同一个机器人，在哪个群 @ 它就默认管哪个范围（总控群管所有仓，项目群管这个仓，需求讨论群管这一张需求；细表见 design 15.4）。
2. 群都按需开，靠点按钮开，不靠打字：总控群置顶盘面卡上「开项目群」（选仓）；项目群里每张需求卡上「开讨论群」。
3. 只 @ 它不说事（hi、帮助）＝ 弹这个群的菜单卡。
4. 一件事一个话题：它开的任务、答的追问都回在话题里，进度原地更新，做完给 PR 链接。
5. 群菜单和会话标签页放链接入口：驾驶舱、需求文档。

## 要什么

- 网关：群 → 范围的绑定（总控 / 仓 / 需求）；话题回复；菜单卡；开群按钮与选仓下拉；建群后挂群菜单和标签页。
- 后端：绑定关系落库；按范围回答（盘面、进度、追问）；建群、归档的接口。
- 讨论群的拍板期、整理、归档照 #31。

## 怎么算做完

- 用授权的测试身份端到端：总控群点「开项目群」建出项目群 → 项目群里记一句成需求 → 点「开讨论群」建出讨论群 → 三个群里各 @ 一次「进度」，答的范围各不同 → 只 @ 不说事弹出各自的菜单卡。
