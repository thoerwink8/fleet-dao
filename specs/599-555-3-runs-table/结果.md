## 交付了什么

- **`packages/db/src/schema/runs.ts`**（117 行）：新表 `runs`（v3 三段一条龙每段每次跑一次的流水账）。字段对照 `packages/engine/src/runner/not-wired.ts` 的 `RunRecord`：id、segment（scope / manual / verify 三择一）、taskId（可空，外键 → tasks）、issueNumber、model、channel、startedAt / endedAt、outcome（done / timeout / killed / spawn_failed / admission_blocked / failed）/ inputTokens / outputTokens / cacheReadTokens / cacheWriteTokens / costUsd / memoryPeakMb / failureReason / prNumber / branch / workflowId / temporalRunId / retryOf（自引用）/ createdAt / updatedAt。

- **`packages/db/src/queries/verify.ts`**（135 行）：`saveVerifyRound` 同一次写入两头都落——`verify_rounds` 记细节（criteria / report / verdict / 驳回，照原样）、`runs` 记流水（segment='verify'，**id 与 verify_rounds 同一根**，当 join 键用）；`model` 从 `routes` 拿 `modelId`，找不到就**明确报错**（不拿空字符串顶、也不让外键给我们兜底报一条不干净的错）。`verifyRoundsOfTask` 返回形状照旧——**老行**（本切片上线前只有 `verify_rounds`、没 `runs` 流水的）照样读得到，不手工合并、不迁数据。
- **`packages/db/test/runs.test.ts`**（303 行，20 个用例）：11 个故意造红 + 9 个正常路径。
