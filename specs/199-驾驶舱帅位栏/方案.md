# 驾驶舱帅位栏（#199）

对应需求：`specs/199-驾驶舱帅位栏/需求.md`。首页一栏三块：要你定的（能点选项）、在做的（每步状态和更新时间）、最近动态（新的在上）。数据只在法国库。读不到写「没读到」和原因。本机进度页停用。

## 定了什么

本机 `~/.local/share/fleet-progress/` 不再当账本。帅位经现成的 ssh 调法国 `fleet-api`（和 `claim.mjs` 同一条路），写进新表；驾驶舱沿用已经在跑的 SSE（库一变就推，页面重拉）。点选项只改库，这条立刻从栏里消失；帅位会话下次来读，把选中的写进那张 GitHub 单的评论，再记账。

「放开 fleet 汇报给任何会话」落在这条路上：不靠引擎签发的 `FLEET_TOKEN`，本机会话也能报。引擎会话的 `fleet plan` / `say` 仍写 `progress_events`，任务详情照旧，不灌进这一栏。

不选的两条：

| 做法 | 为什么不 |
|---|---|
| 造一条假的 `session_runs` 去复用 `progress_events` | `route_id` 必填，会混进额度和选路 |
| 把 `/agent/v1` 开出本机、给任意会话发令牌 | `packages/api/src/app.ts` 写明这个口只听本机回环 |

对照（2026-09-28 查）：服务器往页面推、点击走普通 HTTP，见 [WebSocket.org 对 SSE 的比较](https://websocket.org/comparisons/sse/)（2026-03-10）和 [Koder.ai 的看板一文](https://koder.ai/blog/websockets-vs-sse-live-dashboards)（2025-11-28）。决定和动态只存一处，页面是投影（#169：盘面为准；两份清单会对不上，见 [agentdash#788](https://github.com/thetangstr/agentdash/issues/788)）。所以删掉「本机 JSON 再同步一份」这一层，不留双写。

写入要带现任帅位的机器、会话、任期，库里对不上就拒（退出码 3），不写成空的成功。技能里座位那几条不动，归 #349。这里只改「报进度」。法国引擎页 `france.html`（#328）这张单不删，它还等 #216。

## 库

`packages/db/src/schema/seat.ts` 加 `seat_boards`：`id`（uuid，主键，给现成的 `fleet_notify_change('id')` 用）、`scope`、`project`，`(scope, project)` 唯一。`scope = main` 才进首页，`drill:*` 不进。

一份板一行，四段 jsonb（都必须是数组，库约束兜住）：

- `steps`：`{id, order, title, status, detail, updatedAt, links}`。`status` 只许 `done` / `doing` / `waiting` / `needs` / `blocked`。`updatedAt` 用库的 `now()`，不信本机时钟。
- `log`：`{at, text}`，最多 60 条，新的在前。
- `needs`：还没拍的 `{id, question, options, recommended, repo, issue}`。`recommended` 必须在 `options` 里，`issue` 是正整数。
- `answers`：拍过的，多 `option`、`answeredAt`、`answeredBy`、`ackedAt`。点了就从 `needs` 挪到这里；`ackedAt` 空着表示会话还没写进单子。

判法放 `packages/core/src/seat.ts`（状态、选项在不在列表里、推荐项在不在）。接口和脚本都调它。写入同一行时 `SELECT … FOR UPDATE`，点选项和报一步不会互相盖掉。

迁移：改完 schema 在 `packages/db` 跑 `pnpm db:generate`，再在生成的 SQL 末尾按 `migrations/0001_triggers.sql` 挂 `fleet_notify_change('id')`（drizzle-kit 生成不了触发器）。`packages/shared/src/realtime.ts` 的 `REALTIME_TABLES` 只加 `seat_boards`，不改名、不删。`packages/db/test/notify.test.ts` 补一次插入，否则「每张表都发出通知」会红。只加表和触发器，不改旧行。

## 谁写、谁读

法国 `fleet-api seat board`（挂在现有 `seat` 下面，退出码跟 seat/claim：0 成了，1 没做成，2 参数，3 不是现任）：

- `put`：一句话、加一步、改一步状态、加一条动态、加一条要拍的、清空要拍的。
- `pending`：已拍、还没记账的。
- `ack`：评论写进单子之后才记 `ackedAt`。

本机 `p.mjs` 的子命令保持 `head` / `add` / `step` / `log` / `link` / `show`，改成走 `seat-lib.mjs` 的 `callFrance`。`needs` 改成能点的：

```bash
node p.mjs <项目> needs add <id> --issue <号> --repo <owner/仓> --recommend <选项> <问题> <选项…>
node p.mjs <项目> pending
node p.mjs <项目> record
```

`record`：对每条 pending 用 `gh` 在那张 issue 留一句「创始人拍了：<问题> → <选项>」（只这一句，不写账号、邮箱、IP），成功再 `ack`。`gh` 失败就退出非 0，这条继续留在 pending。没配法国钥匙：退出码 2，写明原因，不写本地文件冒充成功。身份从本机帅位状态读（`seat.mjs` 留下的那份）；还不是现任就说明原因并退出。

驾驶舱（登录后的现成接口，不新开监听）：

- `GET /api/seat-board`：只 `main`。没有任何行是 200 加空列表。库出错是 500，正文带原因。
- `POST /api/seat-board/needs/:id/answer`：选项必须在列表里。写上回答。重复点 409，这条保持已回答。

页面放在 `routes/board.tsx` 的 `FlowBanner` 下面，电脑画布和手机树（`max-width: 767px`）都有。标题从品牌读：`brand` 加一个字段，正式版写「帅位」，演示版换一个不在 `packages/web/src/build/scan.ts` 禁用词里的说法。组件源码里不写死「帅位」「驾驶舱」「fleet」，演示包扫描会失败。三块标题：要你定的、在做的、最近动态。读失败：整栏「没读到」加原因，三块都不渲染。读成功但空：各块写「没有」，不要写成「没读到」。

推送：`packages/web/src/api/client.tsx` 的 `TABLE_KEYS` 加上 `seat_boards`，重拉这一栏。不另做轮询。写进库到页面重拉走现成 SSE，短于 10 秒。
