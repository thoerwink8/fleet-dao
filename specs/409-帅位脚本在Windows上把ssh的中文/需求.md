# 帅位脚本在 Windows 上把 ssh 的中文报错打成八进制转义，连不上法国时原因读不出（#409）

#351 演练第 6 步撞到的：Windows 上 `seat.mjs`、`claim.mjs` 连不上法国时，ssh 的中文报错（系统是 GBK）被打成 `\262\273\326\252…` 这样的八进制转义，人读不出原因（本来是「不知道这样的主机。」）。退出码、「按不是帅位算」都对，只是原因那句看不懂。

## 怎么算做完

- `seat-lib.mjs` 读 ssh 的标准错误时，认出 GBK 字节（或 ssh 打的 `\NNN` 转义）转成正常中文再抹字；认不出的照原样留着、不吞。
- 测试：喂一段 GBK 的「不知道这样的主机。」（和转义后的样子）各一条，打出来是能读的中文；故意喂坏字节，原样留着不报错。
