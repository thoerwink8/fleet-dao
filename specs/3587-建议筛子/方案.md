## 筛子

**前提**：创始人 2026-10-22（#3587）要 GPT 继续参与发现问题、让系统越来越好；0089、0091「落后的都要删除」「非必要不添加」「不打补丁」；0006 讨论和冷验收的族顺序 GPT 打头（创始人定的，筛子不改）；`docs/goals.md` 第五节 12 条必须守；0082 放宽或删除前先读源码弄清它为什么在。

**1. 发现分四类，各走一条路**

- **F1 现场故障**：有单号、run id、日志或创始人看得见的现象。可以改代码，修在必经的那一步；修复不许顺手加新护栏，要加走 F3。
- **F2 推测**：「可能」「如果」「没处理某种边界」，还没发生过。只记进候选池（开未排期的单、标题写「推测」——用现成的「未排期机器不接」，不另造标签），不改代码；真出现一次、挂上那次的单号，才升成 F1。
- **F3 要加护栏**：新钩子或钩子分支、新检查、新 CI 步骤、自动开单或提醒、新状态 / 字段 / 表 / 账、给规矩加句子都算。必须同时：登记表里有一条，带真实失败单号；到期日 ≤ 30 天；写明「到期前真拦下过 ≥ 1 次才留」和次数从哪里数；一进一出（同一个 PR 删一处护栏，或写明为什么不删）。
- **F4 删减**：快车道。写三件事：当初为什么加、守的是第五节哪一条、删了以后那一条由谁守。

**2. 谁来判**

- 机器判：CI 检查新加护栏是否登记、字段全不全、是否一进一出（第一片）；每天复审到期条目，按拦截来源数次数，0 次开删除单，数不出来写「计数没接上」、不当 0（第二片）。
- 另一家判落成什么：GPT 提出发现，由当前写手按复杂度预算定落成什么。预算＝登记表条数，每周不许净增。Codex 指挥官自己发现的问题也只开 F1 或 F2；要加 F3 照样过检查，谁写的都一样。
- 冷验收：拒绝必须对应单子「怎么算做完」里的某一条或一个能复现的失败；推测类意见写进 PR 评论、进候选池，不挡合并（引擎端改，第三片）。

**3. GPT 怎么继续发现问题**：它的输出（`discuss`、冷验收、Codex 巡检）统一写成「发现」：现象、证据链接、影响、类别（F1 / F2），不写「怎么做」「加什么护栏」。无人值守巡检和只读核查开的证据、回执类单，一律改成 F2 进候选池，不再直接开缺陷单（第三片）。

**4. 和现有规矩怎么接**：新写一份决定「建议筛子」，取代 0100 第 6 条「对账红了开单」；`discuss` 技能「挑错」一步改成「GPT 回的是发现，推测类进候选池」；冷验收提示词：推测类意见不挡合并；法国指挥官默认 grok，照样受登记表管；登记表和检查本身按改标准走、事后报。

**5. 拆 PR**

| PR | 做什么 | 验收（diff 里看得见） |
|---|---|---|
| A | 删 audit-alarm（`audit-alarm.ts`、`github-audit.ts` 的 `--alarm` 分支、`github-audit.yml` 的 `--alarm` 和注释、`audit-alarm.test.ts`、`test-timings.json` 对应行、`packages/conventions/AGENTS.md` 和 `docs/design.md` 里的说法）；决定取代 0100 第 6 条 | 上面这些从 diff 里消失；对账不一致时仍退出非 0；`pnpm check` 绿 |
| B | 登记表 `packages/conventions/guards.json` 只记数据，不进 `pnpm check`、不变红；每周进度（#1055）打一行护栏数 | 见下 |

| E | 用复审把存量护栏过一遍 | 每周净减 |

**PR-B 的做完标准**：登记表每条有 id、kind（hook / workflow / alarm / command）、path、evidence（单号数组）、proposer、expires、keepIf、hitSource、outFor 或 whyNotRemove；存量护栏回填，evidence 写「存量未自证」、expires 统一 2026-11-22。登记表只记数据，不进 `pnpm check`、不变红；每周进度（#1055）打一行护栏数（hooks、workflows、ALERT 前缀各几个，净增标出来）；到期复审照第二片。

**为什么不做必过检查**（指挥官拍板，红队证据）：必过检查认不出真正的病根（护栏有没有人看、有没有挡住过事），只认得出「有没有登记」，还给每次减法加一道税；数字上周报里露出来，比变红更便宜也更诚实。

**风险和回退**：B 误红会挡所有 PR，回退＝revert；检测会漏（往已有钩子文件里加分支），先接受，第三片起用钩子规则 id 补。不掏新钱，删的都在 git 里。
