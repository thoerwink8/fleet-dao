## 要什么

- CI：PR 恰好一个类别标签、一个里程碑，正文有「对应计划」「specs」两栏，缺了判红。PR 模板和 renderPrBody 同步加这两栏。
- 开单脚本：缺类别或里程碑就拒绝开单；可选建 specs 骨架。
- 文档指针检查：design、plan、ops、README、specs 里指向仓内文件和章节的引用都要指得到。

## 怎么算做完

- PR 审过合进 main。
- 故意造的缺标签、缺里程碑、缺两栏、断指针，各被拦下一次；main 上现有文档 0 误报。
