# 结果：帅位本机脚本（#347，#299 的子单）

要什么见 [需求.md](需求.md)；方案在 `specs/299-帅位只一个/方案.md`「本机这边」那节。

## 做了什么

- `agents/skills/commander-seat/scripts/seat.mjs`、`claim.mjs`（逻辑都在 `seat-lib.mjs`）：接班、续约、现查、看现状、交接，认领、报一步、做完、放下、看认领，都经 ssh 调法国的 `fleet-api seat` / `claim`（带 `--json` 读回）。登法国的 ssh 名字和「法国引擎」页（`france-lib.mjs`）同一个放法：环境变量 `FLEET_FRANCE_SSH`，其次 `~/.fleet-dao/france-ssh` 第一行不以 # 开头的；原因里不带名字本身，ssh 回的话抹掉像 IP、令牌的。
- 本机记着「我是谁、第几任、上次续约成功」在 `~/.fleet-dao/seat/`：离上次续约成功超过租期，现查不等法国回话直接判不是帅位；续约、现查查到换了人就记成已退役，之后续约、认领都不再去法国，交接说明照样能补。租期设置认不出时法国不接班、座位不动，法国回的租期认不出本机也不记（没有租期就判不了过期，记下就一直算数；第二意见第 1 轮提的）。没登法国的钥匙、ssh 连不上、回的认不出一律退出码 2，按不是帅位算。
- 认领时带 `--branch` 的把认领号记进这个分支的配置（`branch.<分支>.fleetClaim`）；`.githooks/pre-push` 推之前先调 `claim.mjs prepush`：认领作废了、改派了、做完了、库里没有就拦（写明现在归谁），连不上法国、没配登法国的名字只警告、照推，配置认不出拦下；两步（查认领、卫生检查）收到的是同一份标准输入。
- `pnpm issue:new --local`：这台接过帅位（`~/.fleet-dao/seat/` 里有 `main` 的记录）就在开完单时当场替帅位在库里认领（`claim.mjs take --owner seat --label 帅位`），「本机做」标签只挡开单那一刻；没接过的明说只贴了标签；认领没成退出码 3（单已开，别重开）。
- 法国这边：帅位 `claim take` 能把这个座位的帅位自己占着的（开单时替帅位认领的）换给工人（同一个事务里核任期，操作记录记下原来那份），工人拿着的照旧换不了（那是改派，#348）；演练要的 `claim take --owner engine`，只在演练座位下允许，走引擎接活用的同一个库函数，记在演练座位名下、待起补起不碰它、不起工作流。
- 技能说明没动（改标准那一步是 #349）。

## 怎么验证的

- 测试（每条失败路径各造一次）：`agents/test/seat-claim.test.ts`（没登法国的钥匙、ssh 连不上、回的不是 JSON、接班结果对不上、法国说没做成、退出码认不出；超过租期现查不去法国；换了人退役、退役后不再去法国但交接能补；没接过班、好几份记录、记录坏了；认领的 git 配置和镜子、演练座位不改镜子、别人拿着、不是帅位、旧认领号；推前钩子的放行、拦下、只警告；钩子两步收到同一份标准输入、查认领拦下时卫生检查不跑）；`packages/api/test/store-contract-seat.ts`（帅位占着的换给工人，内存版和 Postgres 版）；`packages/api/test/cli-seat.test.ts`（演练的引擎那一边）；`packages/conventions/test/issue-new.test.ts`（开单后认领、这台接没接过帅位）。
- 本机真跑一次（2026-09-27 夜，法国跑的是当时主线 1185af3，库和命令 #320、引擎接进认领 #346 都在上面；脚本是这个 PR 里的）：演练座位 `drill:299`、演练单 #365（`pnpm issue:new --local --milestone 未排期` 开的，那一下这台没接过真帅位，开单脚本照实打了「只贴了「本机做」，库里没认领」）。
  - `seat.mjs take --scope drill:299 --session d347`：「接班了：drill:299 第 1 任是 本机/d347；座位原来没人。租期 45 分钟」；`check`：「是帅位：drill:299 第 1 任，租约到 …（库的时钟）」。
  - `claim.mjs take 365 --scope drill:299 --label w347 --branch drill/365-probe`：认领号 2089a426…，宽限期 120 分钟；分支配置记上了 `thoerwink8/fleet-dao#365:2089a426-…`。
  - 推前查认领（喂钩子那一行）：认领活着时「还归你」、退出码 0；做完之后「你的认领已经结束（done：…）」、退出码 1。
  - `step`（带一句进度）、`done` 都退出码 0；拿做完了的认领号再报：退出码 3，「现在归 本机/w347（done…）；你的认领号 2089a426 对不上或已经结束」。
  - `FLEET_FRANCE_SSH` 指到解析不了的名字：`renew` 退出码 2（「没查成：ssh 连不上法国…按不是帅位算」）；推前查认领只警告、退出码 0。
  - `claim.mjs show 365 --all`、`seat.mjs show --scope drill:299` 读回和上面一致（认领做完了、心跳时刻、那句进度；座位第 1 任、租期和宽限期是默认值）。
- 帅位占着的换给工人、演练的引擎那一边要等这个 PR 发到法国才真跑得到，由测试覆盖，演练（#351）里真跑。
