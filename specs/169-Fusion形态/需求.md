## 讨论记录

### 第 1 题：叫法（创始人 2026-09-26 拍：选 1）

英文和 Devin 对齐（Cognition 2026-09-11「Fusion in Devin Desktop & CLI」：选 Fusion 时挑两个模型，规划和审查的叫 Lead，干活的叫 Sidekick），界面上中文在前、英文在括号里：

| 中文 | 英文 | 是什么 |
|---|---|---|
| Fusion 模式 | Fusion | 默认：主导模型指挥副手模型 |
| 单模型模式 | Single model | 一张单一个模型从头做到尾，额度不够时用 |
| 主导模型 | Lead | 定方案、拆活、验收、最终审查，尽量少亲自动手 |
| 副手模型 | Sidekick | 各订阅里的便宜模型，干界定清楚的活 |
| 验证模型 | Verifier | 别家模型，开 PR 前对照「怎么算做完」核改动 |
| 评审 | Review | 让别家模型挑错：开工前评方案、开 PR 前评改动 |
| 任务简报 | Brief | 主导模型派给副手的活：目标、范围、约束、怎么算合格、交回格式 |
| 存档点 | Checkpoint | 主导模型随时存的进度，会话断了从这里接着做 |
