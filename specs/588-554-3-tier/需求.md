## 怎么算做完

1. `packages/engine/src/runner/tier.ts` 纯函数 + zod schema `{ tier, effort, reason }`，reason 必非空。
2. 判据按顺序应用：空 → 抛 TierError；>50 个文件 → heavyweight 不 refine；单文件 → fast / medium；同一 `packages/<包>/` 内几个文件 → medium / high；其余 → heavyweight / high。
3. `packages/engine/test/runner/tier.test.ts`：happy path 三档各一 + 故意造红（空列表不默认 fast）+ >50 直接 heavy + 同包接口多文件 → medium 边界。
4. 不接 engine、不读 git、不改任何调用方。
5. `pnpm exec vitest run packages/engine/test/runner/` 全绿；`pnpm exec tsc -b` 无错；biome 过。
