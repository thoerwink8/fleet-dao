# #554-2 测试移出会话：done-check 看 PR CI 而非会话自报 · 结果

## 做了什么

**核心：`done-check.ts` 的「判 done」从「会话最后一次跑测试的绿」改成「这张 PR 的 CI 全绿」。**

- `packages/api/src/done-check.ts`：判 done 分两条入口：
  - 调用方带了 PR 编号（554-1 之后是常态）：**判 done = 这张 PR 镜像的 `checks === 'success'`**（`checks` 由 `@fleet-dao/github` 的 `mirrorChecks` 汇总必过检查，四态 success/failure/pending/none）。
    - `failure` → 422 done_rejected，reasons 点名这张 PR 的 CI 是红的。
    - `pending` / `none` → 409 not_verifiable_yet，分别写明「CI 还在跑」「CI 还没起」。
    - PR 镜像库里还没有 → 409 not_verifiable_yet，写明「还没同步进库」。**不拿空当绿**。
    - 仍然顺带核 PR 分支和状态（没被关、是本会话的分支）。
  - 不带 PR 编号（Fusion 旧流程「会话只在本地提交、PR 引擎后开」还在用，`packages/engine/src/workflows/` 本切片不动）：**fallback 保留** 旧判（看 `lastSessionTest`），原样退回（含「开工时没记下测试命令」「最后一次测认不出」「最后一次没过」）。
  - 头部注释说明两条判法为什么都在、什么时候剃掉 fallback。

- `packages/engine/src/real/prompts.ts`（`codeBlock`）：写码阶段提示词**删掉**「交活只认会话里原样跑的 `pnpm test:changed`」和「别接管道、别放后台」，改成「测试由 CI 跑，不在会话里跑测试」。Lead.takeover 那步也复用 codeBlock，提示词一样变。`repo.testCommand` 参数照旧接，**只是不再被 codeBlock 用**（556-4 下线时再清）。

- 单：#592（v3 三段一条龙、#554 子单），完整需求在 `specs/592-554-2-done-check/需求.md`。

**没动**：`packages/engine/src/real/flow-gate.ts`（起会话的 testCommand 链路）、`.fleet/flow.json` 的 `testCommand` 字段、`packages/engine/src/real/sessions.ts`、`packages/engine/src/workflows/*`、`.github/workflows/`、`packages/db/migrations/`、`packages/conventions/{standard,high-risk}-paths.json`。
