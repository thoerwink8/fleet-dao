#589 home-api 合进主线之后（主页骨架 + 接通数据都进了 `origin/main`），旧的两页——按仓的全局任务树（`/` 的看板画布）和全仓总览 `/overview`——可以整个删掉了。本切片把它们和它们独用的代码（React Flow 画布、ELK 布局、flow-source 横幅、看板模型）整个删干净，把主页挪到 `/`。

# 场景

主页三块「要你拍的 / 在跑的 / 做完的」是三段一条龙的形状在英文上的落点。看板画布是多人 Fusion 时代「阶段挂在哪条路由」的可视化，删编排层的本切片，前端这一页跟着走。总览里的三部分（各仓条、等你处理、此刻额度）本就在主页的持续状态条、通知中心、调度台各自收编，留着就是两份「一屏」互相重叠。

2. `routes/board.tsx`、`routes/overview.tsx`、`board/` 目录不在仓里。
3. 侧栏导航第一组是「主页 /」（/tasks 由并行的 #611 删走）；顶栏仓切换没有「全部仓 · 总览」；⌘K 没有看板过滤的两条快捷。
4. 飞书 `COCKPIT_PATHS.overview` 指向 `/`，按钮链接和「没找到 #X」文字对得上。
