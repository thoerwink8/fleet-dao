# 驾驶舱用户视角 e2e：缺陷清单（母单 #902）

创始人 2026-10-05 原话：「驾驶舱需要和后端搭配，站在用户角度上e2e」。

怎么测的：真 Postgres 16 + 线上同一个入口的真后端（`packages/api/src/main.ts`，`DATABASE_URL`）+ Vite + 本机 Chrome，数据走发布同一条装载链再灌业务数据（`packages/api/test/e2e/prepare.ts`）；用例在 `packages/web/e2e/specs/`，起法和手动跑法见 `packages/web/e2e/README.md`。每页 1920×1080 和 1366×768 各一张截图在 `_tmp/e2e/<尺寸>/`（本机临时目录，不进仓）。
严重度：P1 = 创始人按剧本走不下去；P2 = 看得到但说错话、少功能；P3 = 小毛病或臃肿。

## 没发现问题的（已用真数据验过）

- 登录：没登录打开任何页面被带到 `/login?next=…`；账密错回 401 `bad_credentials`、不发会话；登录成功后账号菜单写着「创始人甲」；退出后旧会话回 401、再开任何页又被带去登录、操作记录有 `logout`。
- 主页（#914 之后）：「要你拍的 / 做完的」和 `/api/home` 一致；流水线图每张单一个节点、落在它真所在的那一段（#12 动手在跑、#17 验收还没起=还没验、#15 排队=对题；这些段是用引擎自己的 startRun / finishRun 写进 runs 表的），泳道头在途数、平均耗时（没样本写「还没有跑完的样本」不写 0）、点节点进详情、读不到时写「主页没读成」+ 重试、深色主题真换色、手机宽度（390×844）导航收成抽屉且没有横向滚动条。
- 单子详情：#13 总耗时 1 小时 26 分、干活合计 1 小时 10 分、各段耗时、超时那一笔的原因、「没读到」不写成 0、按单号兜底的标记，都和库里的流水对得上；没跑过的单写「还没跑过」；不存在的单明确写错并给回主页。
- 额度：拼车 $38 / $100、独享 55% / 31%、过期的池标「过期」、一次没读成的写「没查成」、挂着拼车、烧速「约 N 分钟后用满」（和后端同一个数）、拼车对账「接口说用了 $38、本机没记到」。
- 设置：「引擎暂不用独享」拨开 → 库里第 1 版、进操作记录、刷新还在、额度页也跟着说；同时跑的会话上限和留量线改了落库、版本 +1、进操作记录；带过期版本号保存回 409；填 99 当场拦住。
- 提醒：按级别分开数；点「回答」选一个选项落库、进操作记录、主页那条追问没了、再答回 409；「处理了」落库、进操作记录、「全部」里写明谁处理的。
- 后端断开（连接断开 / 回 500）：整页写「没能确认登录」+ 原因 + 重试；单页写「没读成」+ 原因 + 重试，后端好了点重试数据回来；改设置时断开，页面明确报错、没有悄悄写进去。

## 契约对账

`shared/src/web-api.ts` 的 `WebRoutes`（29 个）+ `AuthRoutes`（7 个）：

- 契约 ↔ 后端注册的路由：两个方向都对得上（`packages/api/test/web-routes-contract.test.ts`；`POST /auth/dev-login` 只在开发免登开着时才注册，是有意的）。
- 契约 ↔ 前端 `http.ts`：前端没用的只有 `credentials`、`updateCredentials`、`passwordLogin`（D1）和两个飞书整页跳转（不走 fetch）；前端引用的名字都在契约里（`packages/web/src/api/contract.test.ts`）。
- 没有字段缺、类型不一致的：前端 `http.ts` 的每个请求和返回都按契约的 zod 校验（e2e 里走了 27 个接口，没有一次校验失败）。
- 有后端、有前端封装、没有页面用：D6。

## 没做 / 没验证

- 没进 CI：要加 job、碰 `ci.yml`（先审后合），单开子单。
- 只在 Windows + 本机 Chrome + Windows 版 Postgres 16.9 上跑过，Linux / CI 没跑。
- 主页流水线图（#914）：只测了它在真库、真 runs 行上的样子（1920×1080、1366×768、深色、手机宽度），没测空状态「现在没有在跑的单」（要清空库里在跑的单，改库的用例动不了它）。
- 没真起 Temporal 和引擎：暂停/叫停/换模型这类要发信号的动作没走（D3 说了界面上也没入口）；e2e 里 `/healthz` 的 temporal、engine 是红的，页面上这两项只在主页「引擎」格有体现。
