## 怎么算做完

1. `GET /api/home` 返回 HomeResponseSchema：
   - decision[]：level='decision' 通知 + approvals 未决 + asks 未答。checkpoint：/api/notifications（按 level 过滤）+ /api/approvals。
   - running[]：在跑的单。**先做「用标准团本数据源」**：tasks 里的 open tasks 有 open PR（pull_requests.state='OPEN'）。 segment （对题/动手/验收）先由 #556-1+ 落真时补，**现字段先返回 null 或 NotWired**——**还没验**不许用 fail 红。
   - done[]：merged pull_requests 最近 10 条 + tasks 反查 issue（issueNumber）。
   - health：pools/route/jobs 的 lastRun + engine_off（desired-config 的 FLEET_SERVICES）。
2. memory-store.ts 和 dev-fixtures.ts 也出 shape 一致的假数据，dev:mock 起 5173 三块可见。
3. first-screen wave 1：把 /api/home 放进 packages/web/test/first-screen.test.tsx 的 wave 1 集合（和 me/repos/notifications 走同一轮）。
4. packages/api/test/home.test.ts：memory-store 和 pg 两种回港，**未验越红不误**（verify_pending 不写成 fail）。
5. 故意造红：拉不到数据不能拿空当成功（每个源都明确失败）。
