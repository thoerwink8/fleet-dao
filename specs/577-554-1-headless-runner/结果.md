# #554-1 无头一次性子进程段 runner（#577）· 结果

关联 PR：#581 · 分支 `feat/554-1-headless-runner`（已挂自动合并）

## 做了什么

- 三段一条龙（#509 / #554）的**骨架**：把「起一次无头会话、喂一份交代、干完退出、记一笔」做成可调用的接口。
- 新增 `packages/engine/src/runner/`：
  - `brief.ts`：三份 Brief（scope / manual / verify）+ `renderBrief()`；照 `ports.ts:168-233` 的 SessionBrief 借字段（title / request / acceptance / touches / branch / prNumber / head / specDir），**不带** Fusion 专词。Verify 必带 diff、baseSha、headSha、changedFiles。
  - `one-shot.ts`：起子进程 + 超时 kill（默认 60 分钟）+ 落盘 `_tmp/<runId>/`（stdout / stderr / result.json / brief.txt；TTL 24h）+ 记 runs + 起前内存准入（沿用 `real/memory-admission.ts`）。Spawner 依赖注入。**不许续会话**（接 `resumeSessionId` 当场抛 `OneShotError RESUME_FORBIDDEN`）；不跑测试；不保留 `.fleet-out/` 进度事件。
  - `verdict.ts`：按段判成败（judgeScope / judgeManual / judgeVerify）。**空 stdout + exit!=0 一律 failed**；manual 必带 PR# / branch / headSha / changedFiles，缺一就 failed；verify 必写 pass 或 fail，又 pass 又 fail 也 failed（一句话说不清就是没结论）。
  - `not-wired.ts`：runs 表还没建（#556），用 NotWired 占位写入（落 JSONL 到 `_tmp/runs-not-wired/<日期>.jsonl`，形状由 `RunRecord` zod schema 钉死）。「交给 #556 的 runs 写入约定」写在 `specs/577-.../需求.md` 一节。
- 新增 `packages/engine/src/segments/{scope,manual,verify}.ts`：三段各自的入口，只调 one-shot + brief + verdict。**verify 的 PR# 是参数**（specs/509「验收那一遍现读，不存副本」「不许跨进程翻上一段的 PR#」）。
- `packages/engine/package.json` 加 `"zod": "^4.6.5"`（和 core / shared 一致）。
- **不动**：`packages/engine/src/workflows/{fusion,requirement,subtask,merge-queue}.ts`、`real/sessions.ts`、`packages/api/src/done-check.ts`。
