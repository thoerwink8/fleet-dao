# 待审的 4 张单

## #201 给 Fusion 调度器加并发上限配置

### 场景
Fusion 调度器同时起的任务太多，想加一个配置项限住。

### 怎么算做完
1. Fusion 调度器读 `FUSION_MAX_CONCURRENT`，超过就排队。

## #202 hygiene 检查要拦 `.pem` 文件

### 场景
私钥文件被误提交时要在推送前挡住。

### 怎么算做完
1. 文件名是 `*.pem` 的文件被卫生检查报出。
2. 有测试覆盖。

## #203 发版车结束后自动恢复接活开关

### 场景

### 怎么算做完

2. 恢复不成功报警。
