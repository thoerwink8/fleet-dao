# 待审的 4 张单

## #101 引擎启动时打印版本号

### 场景
排查问题时不知道线上跑的是哪一版。

### 怎么算做完
1. 引擎启动日志第一行带 `version=<提交号>`。
2. 有一条测试核对这行日志的格式。

## #102 驾驶舱「任务」页加按状态筛选

### 场景
任务多了之后找失败的很费劲。

### 怎么算做完
1. 任务页有状态下拉：全部、进行中、失败、完成。
2. 选了之后列表只显示该状态。
3. 刷新页面后筛选状态保留（写进地址栏参数）。

## #103 把 `legacyExport` 的输出格式改成 JSON Lines

### 场景
导出的数据下游要逐行读取，现在是一整个 JSON 数组。

### 怎么算做完
1. `legacyExport` 每行输出一个 JSON 对象。
2. 老的数组格式不再输出。

## #104 失败任务自动重试时在飞书发一条通知

### 场景
自动重试悄悄发生，创始人不知道。

### 怎么算做完
1. 每次自动重试发一条飞书消息，带单号和第几次。
2. 有测试覆盖「重试时发消息」和「不重试时不发」。
