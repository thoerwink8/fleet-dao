# cli：`fleet` 命令（业务说明）

> 一句话：AI 会话（工人）里敲的那条 `fleet` 命令——汇报进度、提问、说话、交活、说卡住了、翻历史；进程无关的一层薄壳：**解析参数 → 按约定本地校验 → 带通行证和幂等键调后端 → 用白话打印结果**；读者是 AI 会话，也是人。
> 出处：`packages/cli/package.json` 说明；`src/` 各文件头注释（5 个文件，26 KB）；`test/`（3 个文件，49 条用例）；`shared/src/agent-api.ts`（命令 ⇄ 后端接口约定）；`packages/api/src/agent.ts`（`api.md` 第 5–10 条）。

## 一、干什么、不干什么

- **干**：子命令 `task`、`plan`、`say`、`ask`、`history`、`done`、`blocked`、`help`；环境变量 `FLEET_API`（后端地址）、`FLEET_TOKEN`（引擎给这一次会话签的令牌）；退出码约定；`help.ts` 是 `fleet --help` 的全部文字（每条命令什么时候用、怎么写、例子）。
- **不干**：推分支、开 PR、合并（那是引擎；`fleet done` 只交「本地提交 + 会话里跑过的测试」）；任何调度或改调度台（令牌不能合并、不能改调度台）。

## 二、业务规则（每条标出处）

1. **令牌和幂等键**：请求头 `Authorization: Bearer <FLEET_TOKEN>`，令牌只对一个任务的一次会话有效、过期即失效；每次请求带**幂等键**（重试同一条命令用同一个键）。**缺 `FLEET_API` 或 `FLEET_TOKEN`：用法错（退出码 2）并说清缺哪个**；不认识的子命令、多余的选项：用法错、不发请求。——`client.ts`、`cli.ts`；`cli.test.ts`「说明与用法」、`bin.test.ts`。
2. **退出码**：0 成功；1 连不上/后端一直出错（大声失败、写清地址和原因）；2 用法错；3 通行证无效或过期（**不重试**）；4 后端退回（要改了再交：没带推荐的 `ask`、核实没过的 `done`，原因原样打出来，AI 照着补）。——`cli.ts`、`help.ts`；`cli.test.ts`。
3. **重试**：后端暂时不可用（503/连不上/超时）按 0.5 / 1 / 2 秒退避重试、**同一个幂等键**；连不上试 3 次后大声失败（退出码 1）；后端一直 500 试满 4 次后退出码 1；请求超时也重试、最后按后端出错退出；**后端回的不是 JSON、数据不合约定：算后端出错**（不把坏数据打给会话）。——`client.ts`；`cli.test.ts`「连不上与出错」。
4. `task`：`GET /agent/v1/task`，打印需求、做完标准、要改哪里、步骤（`--json` 原样输出）；引擎还没建分支（后端不带 `branch`）：照样打印、分支写「还没建」。
5. `plan`：用 markdown 勾选框写状态、**整张替换**、打印进度；**同一时间两步在进行：本地挡下、不发请求**（后端也会 400）；不带参数：读任务里的当前步骤。
6. `say`：多个参数拼成一句；**空话和超过 500 字：本地挡下**。
7. `ask`：**带选项和推荐**（选项超过 4 个本地挡下）；后端当场回「按推荐先做」，打印「**别停下等回答**」；超出这张单范围（另开单等他拍、这张单绕开）、碰人闸（先按推荐做、合并前等批）、创始人回过这一句：各有各的说法；**不等回答了**：`--no-wait` 这个老写法不认（本地挡下），不会发出一条去等；后端退回（没带推荐）：退出码 4、原因原样打出来。——#259；`api.md` 第 9 条。
8. `history`：`POST /agent/v1/history`，带条数（不给用约定的默认 5；条数不是 1–20 的整数本地挡下）、逐条打印、找不到就直说。
9. `done`：`POST /agent/v1/done`——总结和测试结果；**会话只在本地提交，不带 PR 编号**（`--pr` 已经没有了：推分支、开 PR 是引擎的事，给了算用法错）；说明里教的是本地提交、不教开 PR；**没写测试结果：本地挡下**；后端核实没过退出码 4、原样说出原因；后端错误体 `{ error: { code, message } }` 打出 `message`。——`api.md` 第 10 条（`done-check`）。
10. `blocked`：`POST /agent/v1/blocked`——原因和需要什么；**`--needs` 没写或写错：本地挡下**（`human` 要人拍：后端退回让它带推荐问；`access`：只有他本人才有的东西，照旧停下等人；其余见 `agent-api.ts`）。
11. 打印一律白话、面向 AI 会话（不出现内部代号）；`--json` 给脚本读。——`help.ts`。

## 三、现状（做了 / 没做 / 做坏了）

- **做了**：七个子命令、本地校验、重试与退出码、`--help`；真起可执行入口的验收（`bin.test.ts`）。
- **做坏了**：`done` 的「测试证据」设计和「会话里不跑重检查、全量交给 CI」（`docs/goals.md` 第四节 B）不一致——`fleet done` 现在要求「会话里真跑了交代的那条测试命令」。
- **没做**：三段一条龙里工人向指挥官/副手提问的子命令（`ask` 现在问的是创始人，副手常驻是第七节第 2 条待定）。
