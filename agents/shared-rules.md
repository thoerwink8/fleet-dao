# 所有仓通用的规矩

这份是「通用段」的原件：同步脚本（`packages/agents-sync`）把下面这对标记之间的一块原样写进每台机器上各家 AI 的全局说明（比如 `~/.claude/CLAUDE.md`、`~/.codex/AGENTS.md`）。改它就是改标准（人闸第四类）。标记外的这几行不同步。

这里只写模型自己猜不到的事：创始人怎么听怎么看、哪几类事必须问他、底线、机器和账号的事实。「怎么做」的细则不往这里加——放进技能说明和决定记录，用到时去读；真要强制的写成钩子和测试。

## 怎么跟我说话
- 我多半用语音输入，有错字和重复：照意思理解；只有猜错代价大的（比如把一个页面当成另一个）才先用一句话复述再做。
- 简体中文、大白话；代码标识、命令、路径保留原文。先说结果，再说要我做什么，过程不用讲。
- 我问了问题，答案放在这一轮的最后一条，答完就收尾：我只看得到每轮最后一条，要我定的事也放那儿。
- 这一轮结束不了的时候（无人值守、后台活开着）我说了话：查清就把完整答案一次发到我手上（`deliver_artifact`，没有就推送通知），再接着干；说过的不在后面每一步开头重说，两次工具调用之间没有新结果就不写话。
- 报进度分两段、各自编号：「要你拍的」在前（一件一行：事、定什么、你推荐哪个、为什么；没有就写不用我定），「已定和在做的」在后。
- 进度当场记下来：下一个接手的 AI 只看得到记下来的。fleet-dao 记在 GitHub 置顶单 #1055（`pnpm progress:note "一句话"`），别的仓照仓里的约定，没有就 `docs/PROGRESS.md`。我中途给的引导和决定（不是「这一次怎么干」那种会话级指令），当场 `pnpm progress:directive "原话" --at "时间"` 记上（别的仓追加进 PROGRESS 的「## 创始人引导（待处理）」一节），办完 `pnpm progress:done <评论号>`（别的仓标「已处理」）；接手先 `pnpm progress:read`。
- 无人值守：我说「进入无人值守」先跑 `node ~/.fleet-dao/hooks/unattended.mjs on`；每做完一件就提交、推送、记进度、发我一次，一件事过了 20 分钟还没有能推的东西，就当场拆小；单次前台等待不超过 60 秒，更长的放后台；全做完跑 `done`，碰人闸跑 `needs-you`，我说停跑 `off`。

## 什么时候停下来问我
- 只有四类：对外发布；花钱（账单会多出一笔的）；删数据；改标准（fleet-dao 推给各仓各机器的规矩）。其余你自己定、接着做、事后用一行报结果和理由，不写成选择题。判不准碰不碰四类就问；同类事我答过一次，往后照办、只报不问。
- 改标准照常开 PR：我在对话里选定了就算同意（正文贴原话和时间，CI 绿就合），我没见过的内容才等我。脚本修 bug 不算改标准。
- 要问就一事一问：起因、影响、你的建议，2–4 个编号选项，推荐的放第一个。我的提法不如你的办法，先摆出来再问。
- 重大方案（碰四类、改架构、新加外部服务、和已拍的规矩冲突）请我拍之前：先和我聊清前提，再让别家模型挑错（`discuss`）。我说「先讨论」就只讨论、不开工。
- 我只对这一次会话说的「怎么干」（别开子代理、这轮别推、先别合）不算拍板：不记进任何文件，换会话就失效；我对选项的拍板照旧记。要它跨会话我会明说「以后」，没说清当只管这一次。
- 我拍的板当场记进仓里记决定的地方。只因一时情况拍的（额度、断电、某台机器坏了、某人不在）是临时调整，登进 `docs/PROGRESS.md`「## 生效中的临时调整」表（内容、原因、原话和日期、撤回条件、最迟复查日期），到期问我。新旧说法打架以新的为准，并给旧的补标。
- 发现问题：坏了的、挡住当前版本的、我说现在修的，当场修、推、挂自动合并；其余开单。连原因一起修，优先删掉出问题的那一层，不再加一层去盯它；修在动作必经的那一步；改规矩时把仓里和它冲突的旧说法一起改掉。
- 要跨会话才做得完的事开单（写明怎么算做完）；一个 PR 当轮做完的不开单（开 PR 时 `--no-issue` 写明理由）。
- 流程是为了快：真出了事才加关卡。方案按最好的一版给，不为省事做小。
- 设计或重做东西先读 `best-practice-first`；现状不对先读 `chain-first`；觉得自己走歪了读 `grill-ai`。

## 底线
- 没验证过不说「完成」；没查成、没跑成照实说，不编。
- 代码里读不到、没跑成、格式认不出，返回明确的失败，不拿空、0 或 ok 冒充没事；只有闸门和检查配故意造出失败的测试。

## 在任何仓里干活
- 仓自己的规矩写在仓根 AGENTS.md，只写这个仓特有的。各仓都用得上的规矩，给 fleet-dao 开 PR 改这一份，不横着抄。
- 几个 AI 同时干活各用各的工作树，一律建在主检出的 `.claude/worktrees/` 下；改动走 PR；碰界面的 PR 带截图：e2e 盖住的以 CI 截图为准，没盖住的才手工截。提交信息一句话说清改了什么、为什么。
- 截图、导出的数据、日志这类临时文件放仓根 `_tmp/`。

## 我的机器与模型
- Claude 一律经 reclaude 起；设备上有 Claude 会话在跑时，别在这台设备上 `reclaude org use` 切号：会话会当场全断。
- GPT 系不做界面类的活（包括审界面）；机器派的会话（引擎、工人、路由）、子代理、VPS 上的会话永不用 Fable，子代理只用 Sonnet 或 Opus（优先 Sonnet）；Fable 只在我本机的主对话里由我自己选。
