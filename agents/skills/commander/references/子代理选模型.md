# 子代理选模型（决定 0034、0035）

派 Claude 子代理之前读这一页。创始人 2026-10-09 00:09 授权「改成最具有性价比的调整方案……全程你拍板」，指挥官据此定了三档（决定 0034），取代了「子代理只用 Sonnet 或 Opus」；同日 08:28 要「haiku5.5能力边界你去探查清楚……怎么能大范围使用，节约我的成本」，08:36 指出调到的是 4.5，指挥官实测后把 Haiku 那一档的判据和派法改成下面这样（决定 0035）。「子代理、工人永不用 Fable」不变。

## 原则

1. **能用脚本判的不用模型**（`judge-or-code` 技能）：数文件、比对、巡检采集、判阈值用脚本；模型只管要理解的那一步。
2. **按「产出能不能被脚本或一条命令核对」选档，不按活的名字**（决定 0035）：
   - 产出能被脚本或一条命令核对（`文件:行`、测试过没过、检查脚本 PASS 没有）→ 先给 Haiku 5.5。
   - 没有机器核对、要写进仓里、会合进主线 → Sonnet 5.5（默认档）。
   - 错了会传到所有机器（改标准）、要下结论的评审、架构方案、两次失败的疑难 → Opus 5.5。
3. **级联：先 Haiku、核对不过再升级，不在同档重试**：
   - Haiku：核对它的脚本或命令不过、产出里没有可核对的证据、它自己说拿不准，就升到 Sonnet 重做。它的失败信号本身不可靠，同一个错不值得试第二次。
   - Sonnet、Opus：同档连着失败两次，升一档；到 Opus 还不行回到指挥官自己。
   - 汇报首行的模型 id 对不上要的那一版（见下面「交代必写」），当这次没做、升一档重派。
4. **并发上限仍是 4**，Haiku 也占名额。无人值守时给监控留 1 个，干活的最多 3 个。
5. **有理由可以越档**：表里是默认值，不是死规矩；越档要在交代里写一句为什么。

## 怎么派到真的 Haiku 5.5

- **别名 `haiku` 在本机指向 Haiku 4.5，不是 5.5**（实测：`model: "haiku"` 派出的子代理自报的是 Haiku 4.5 的 id，带日期后缀 20251001）。所以 Agent 工具不写 `model: "haiku"`。
- **写 `subagent_type: "haiku55"`，不传 `model`**（传了会盖过定义文件里的模型）。它是自定义子代理 `~/.claude/agents/haiku55.md`，frontmatter 里 `model: claude-haiku-5-5`；原件在仓里 `agents/subagents/haiku55.md`，`pnpm agents:sync`（开会话钩子也跑）把它装到每台机器的用户级子代理目录，别的仓里也能派（#1393）。会话里没有 `haiku55` 这一类，就是这台还没同步上（`pnpm agents:sync --check` 里 `~/.claude/agents/haiku55.md` 那一行报缺失或漂移）：先跑 `pnpm agents:sync`、重开会话；这次给 Sonnet，不拿 `"haiku"` 顶。
- 命令行要 5.5 就写完整 id：`claude -p --model claude-haiku-5-5 …`。它返回的 `costUSD` 对 5.5 不准（不认识 5.5 的价），不当账；账按官方价（输入 0.10、输出 0.50 美元/百万 token）和实际 token 算。
- 派完核对实际 id：汇报首行不是 `claude-haiku-5-5` 就停，当这次没做、升 Sonnet 重派。

不派子代理的场景：
- 能用脚本判的（数文件、比对、阈值、巡检采集）：脚本，不叫模型（`judge-or-code`）。
- 讨论、让别家挑错：别家模型（`discuss`，默认 GPT；界面类不给 GPT），不派 Claude 子代理。
- 引擎自己接的单、法国上的会话：用的是驾驶舱配的路由，不归本页管。
- 一两条命令就查得清的：自己查，别起子代理（起手固定开销比活大）。

升级路线沿用上面的级联：Haiku 档核对不过 → 同活换对应的 Sonnet 档（`fleet-fixer`→`fleet-builder`，`fleet-triage`/`fleet-review-screen`→`fleet-groomer`/`fleet-reviewer`）；Sonnet 档同档连败两次 → Opus 档（`fleet-debugger`）；再不行回到指挥官自己。越档要在交代里写一句为什么。

## 交代必写

每次派活的交代都写明这几样（另加 `SKILL.md`「子代理的交代要瘦」那四件事）：

1. **模型**：Sonnet、Opus 用 Agent 工具的 `model`，写 `"sonnet"` 或 `"opus"`，不留空；Haiku 5.5 写 `subagent_type: "haiku55"`、不传 `model`（见上面「怎么派到真的 Haiku 5.5」）。要的版本是 `claude-haiku-5-5`、`claude-sonnet-5-5`、`claude-opus-5-5`：交代里要它**汇报首行写自己的模型 id**（它的系统提示里有），对不上就是这台的别名或定义指到了别的版本，当这次没做、升一档重派。能写完整 id 的地方（工人的 `--model-id`、设置里的默认 `CLAUDE_CODE_SUBAGENT_MODEL`、命令行的 `--model`）一律写完整 id、不写别名。
2. **做什么、范围**：只读，还是可写哪些路径。
3. **产出格式和长度上限**：Haiku 一般 ≤10 行。
4. **停下条件**：做到哪一步就停、什么情况回来问。
5. **前台等待**：测试、安装前台跑到完，不拆后台、不轮询。
6. **拿什么核对**（派 Haiku 必写）：派之前就定好核对它的脚本或命令，写进交代。

Haiku 子代理的交代另加：**用到的每条硬规矩都逐条写出来**（实测：只写了 8 条里的 4 条，它就把函数名、事件名也括进了「已知的模块」——没写明的细节它会漏）；限制回合数；输入控制在 100K token 以内；每条结论都附证据（`文件:行`、命令和它的原始输出行）；拿不准就写「拿不准」，不猜。

## 先砍固定开销

每次子代理调用光起手的系统提示和工具说明就要写缓存约 2 万（精简配置：不加载 MCP、不加载技能）到 4.6 万 token（完整配置），比模型差价更值得砍。

- `haiku55` 的定义用精简配置：只给要用的工具，不带技能、不带 MCP（`agents/subagents/haiku55.md` 的 `tools` 白名单只有 Read、Grep、Glob、Bash、Edit、Write）。
- 交代里写回合上限和输出长度；一次能问完的不拆成几次派。
- 同一批相似的小活（几份单子的准入检查）合成一次派，不一份起一个。

## Haiku 的结论怎么用

指挥官据 Haiku 的结论动手之前，自己用一条命令抽查（跑那条核对脚本、读那一行、跑那一条命令）。抽查对不上：这次结论作废，升到 Sonnet 重做。小模型的错答会不声不响地流进总管的结论，这一步不省；小模型评小模型偏松，Haiku 的产出不交给另一个 Haiku 判。

## 无人值守的监控

监控的主体是脚本，不是模型。

- **采集和判定**：约每 10 分钟跑一次 `node ~/.claude/skills/commander/scripts/patrol.mjs`（在主检出根目录跑）。它一次 ssh 只读收齐法国的服务、资源、引擎总开关、没做完的单、定时任务、开着的通知，每项一行带计数和采集时间；和上一次的基线比出 `DELTA`；不变量（服务不 active、磁盘超 85%、可用内存少于 1G、单卡住或停下超过 30 分钟、定时任务最近一次不 ok、新开的通知、引擎总开关关着、在用版本读不到）由脚本判，命中就记进 `ALERT`。
- **基线只由脚本写**：放 `_tmp/patrol-baseline.json`。`OK`、`ALERT` 写新基线，`BROKEN` 不写。模型不碰基线。
- **沉默告警**：ssh 连不上、输出是空的、少了哪一块、库查询报错、采集时间和本机差超过 15 分钟，一律 `VERDICT: BROKEN`，不当 `OK`。
- **指挥官只读最后一行**：
  - `VERDICT: OK`：不叫任何模型，接着等。
  - `VERDICT: ALERT <n>` 且 `DELTA` 不为 0：派一个短命的 `haiku55` 子代理（`subagent_type: "haiku55"`，Haiku 5.5），输入只给那几行 `DELTA`、`ALERT` 和相关日志片段（远小于 100K），它只回证据行和哪几项变了，不归因、不给修法，≤10 行；核对：它回的证据行要在 `patrol.mjs` 的输出里原样找得到。归因和修由指挥官自己或派 Sonnet 做；动手修之前先用一条命令抽查。
  - `VERDICT: ALERT <n>` 但 `DELTA` 是 0：同样的异常上一轮已经报过，不再叫模型；还没处理完就接着处理。
  - `VERDICT: BROKEN`：指挥官亲自巡一次（`node ~/.claude/skills/commander/scripts/france.mjs`）。
- **指挥官亲自巡的三个触发**：连续 3 个周期没读到 `VERDICT` 行；出现 `BROKEN`；据 Haiku 的摘要要动手修之前。
- **自检**：无人值守跨天时，每天至少跑一次 `patrol.mjs --selftest`。它拿固定的假输出验 `ALERT`、`BROKEN` 的判法还灵；最后一行不是 `SELFTEST: OK` 就当监控失效，亲自巡，并修脚本。
- **不做**：不起一个无限循环盯盘的子代理（上下文会涨、会被截断、会话一断就没了）；不每个周期都叫模型。
