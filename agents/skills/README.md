# 方法类 skill

## 这里放什么

各仓都用得上的思考方法和角色（比如帅位 `commander-seat`），每个一个目录，里面一份 `SKILL.md`：frontmatter 的 `description` 一句话写什么时候读，正文写怎么做。只对某一个仓有用的流程、脚本、钩子不放这里。

个别 skill 带脚本，放在它自己目录的 `scripts/` 下（比如 `commander-seat` 的本机进度页），同步时连子目录整个拷过去。脚本的数据写到家目录里，不写进 skill 目录：同步见 skill 目录里多了文件，会把整个目录换回仓里的样子。

## 怎么分发

由规矩同步脚本 `packages/agents-sync` 分发，见 `docs/design.md`「三、已定（共识）」第 16 条：这里有几个目录就分发几个，拷进各家 AI 的 skill 目录；从这里删掉的，下次同步会从各家那里撤掉。

## 加新 skill 的门槛

至少两个仓用得上，才从别的仓提回这里；只有一个仓用得上的，留在那个仓里。
