# `discuss`：讨论

## 何时用

- 重大方案要请人拍之前：碰人闸（对外发布、花钱、删数据、改标准）、和已拍的规矩冲突、新加外部服务、改架构或改阶段划分（和引擎同一条判据，design 第五节「重大方案人拍」）。
- 用户说「出设计题」「先出盲设计题」「讨论一下」「让别家看看」。

小方案 AI 直接定，不用讨论；小选择题（已经收敛成 A 还是 B）也不用。

## 先和创始人把前提聊清楚

方案里有他没说清、没认同的前提（比如一对一还是一对多），先用大白话问他一两句，讨论到方向一致，再找别家挑错。前提没对齐，别家讨论得再细也是在错的前提上打磨。

## 做法：每轮一问一答，没收敛能接着聊

每轮都是一问一答：不读仓、不跑命令、限 400 字、中等思考强度，每家 30 秒内。

1. **第 0 轮，各自独立答**（要盲设计时才做）：只写题面（背景、诉求、要回答的），**不带自己的方案**。题面一字不提示期望的方案形态。
2. **挑错**：自己的方案（有第 0 轮就连同它的答案）发给 GPT，要它说框架对不对、漏了什么、选项怎么改。
3. **接着聊**：它的意见你不认、或者冒出新分歧，把你的回应和新证据发回去接着聊。停在三种时候：意见一致；分歧说清（双方主张没变、证据没新增，写清各方理由和你推荐哪个）；到上限（本机先按 5 轮）。停了以后要重新拉起，得写明能改变结论的新证据。

材料里附上相关规则原文、数据和出处（对方看不到仓，漏写的事实它就不知道）。挑错轮的题面要带【推演】段：从创始人的角度把方案走一遍，按阶段列边界和最坏情况（缺了 `ask.mjs` 不发、退出码 2）。

## 交给人

只写三样：各家一致的、还剩的分歧、推荐哪个。对方的每条意见写明收没收、为什么。讨论是 AI 之间的事，人只拍板。

## 本机工具

脚本在本技能的 `scripts/` 目录，下面写成 `$S`（Claude Code 是 `~/.claude/skills/discuss/scripts`，别家是 `~/.agents/skills/discuss/scripts`）；`ask.mjs` 要这台机器上装好、登录好的 Cursor 命令行（`cursor-agent login`）。**先查装没装**（`cursor-agent status` 跑得起来）：没装的机器上 `ask.mjs` 直接退出码 2，照实报「这台没装、没讨论成」，别临时拿别的工具或自己再想一遍冒充讨论；反方（`second-opinion.mjs`）走 Mirasim，不要 Cursor。

`node $S/ask.mjs --text 题面.md --round <0|1|2…> [--models gpt] [--limit 45]`

- `--round 0` 是各自独立答，1 起是挑错。默认只问 GPT；要盲设计、或者 GPT 答不上时才加别家（`--models gpt,kimi,glm`，最多 3 家：本机同时有工人在跑，五家齐跑加工人顶满进程数，宿主崩过）。界面类的题不找 GPT，换 Kimi 或 GLM。
- 每家一个 `cursor-agent --mode ask` 只读会话（空目录、不读仓），硬上限 30 秒（GPT 偶尔要 `--limit 45`）；超时、退出码非 0、没输出都照实记成「没答上」。退出码 2 = 没讨论成（一家都没答上，或这台没装、没登录 Cursor 命令行），别拿自己的方案冒充结论。
- 接着聊：把上一轮的原话、你的回应和新证据写进新题面再问一次（`ask.mjs` 每次都是新会话，所以上一轮要贴全）。
- 拍板前要一个不同厂商的「反方」读整份分析：`node $S/second-opinion.mjs --text 材料.md --author-family <族[,族…]>`（其余选项见脚本开头注释）。退出码 0 同意、1 有异议、2 没查成，2 不算同意。`--author-family` 显式写当前作者的模型族，同族的跳过。
