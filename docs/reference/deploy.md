### 1.2 旧系统占过的本机端口

旧系统听过 4316（mirasim-server）、4315（mirasim-bridge，已弃用）、4317（responses-chat-bridge）。新的会话 Mirasim 端口避开这三个。引擎认端口靠现读 `local-<端口>.token` 的文件名。

- **P01** root 在服务用户目录里留下 root 属主的文件，之后会以不像权限问题的样子出错。root 只负责安装。写进服务用户家目录的步骤用服务用户自己的身份。
- **P02** root 执行服务用户能改的脚本，等于提权。有效 User 是 root 的单元，ExecStart 链上的文件全属 root、他人不可写。
- **P03** `runuser -u` 不会换 HOME。CLI 会去读调用者家里的配置，然后 permission denied。要显式给对的 HOME。
- **P06** `Restart=on-failure` 不管干净退出。退出码 0 或被 SIGTERM 都算成功，服务就这么躺着。要一直在的单元用 `Restart=always`。
- **P09** 刚 `enable --now` 的那一瞬，NEXT 可能还没算出来。从没激活过的 oneshot，`OnUnitActiveSec` 会一直空转。装完要读回下一次触发时间。
- **P10** 早期 `systemd-run` 起的临时单元会遮住同名的文件单元。旧名字占着端口时，新单元一直崩溃重启。
- **P12** 「查出问题」不要表达成 systemd failed，否则噪音盖住真故障。没做成才非零退出；查出问题并报了警，退出码仍是 0。
- **P28** 测试不带账目录参数，就会写进跑测试那台机器上真正的家目录。测试必须把账和观测指到临时目录。
- **P33** 同一个 CLI 可能有两份（包管理器和自更新的二进制），跑哪份取决于 PATH。跟最新、只留一份，调用时写绝对路径，不钉版本，也不把模型 id 写死在配置里。
- **P39** 去掉 `MIRASIM_NO_AGENT_EGRESS` 大约 90 秒后，reclaude 设备就被服务端解绑，要人重新登录。

备份一行：看门狗按「最近一次成功备份 ≤ 26 小时」判新鲜。过期分钟要盖住周期、失败重试和一轮耗时。
