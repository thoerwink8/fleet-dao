# 驾驶舱界面规范

母单 #1844，方案 `specs/1844-驾驶舱设计规范/方案.md`。这份是定稿：改驾驶舱界面（`packages/web`）先读它。
令牌在 `packages/web/src/app.css`，检查是 `packages/web/scripts/lint-design.ts`，由 `src/test/lint-design.test.ts` 守着（CI 必过）。
令牌改了，同一个 PR 改这份文档。

## 一、视觉基调

参照 Linear 的克制、Vercel Geist 的字阶分工、GitHub Primer 的行密度和令牌分层。八条：

1. 字号只有六档，桌面参照苹果 macOS HIG，中文最小 12px。次要文字在每套主题上都 ≥4.5:1。
2. 数字用无衬线加等宽数字（tabular-nums）。只有编号、提交号、路由号、模型 id、代码用 `font-mono`。
3. 最多两层容器：页面 → 区块。区块里用分隔线和行，不再套卡片。
4. 圆角：控件 6px，卡片和弹层 10px，标签全圆。
5. 阴影只表示「浮起」。卡片在亮色下只有一根下边线，暗色下没有阴影。
6. 状态色三种用法：实色（点、条、图标）、淡底（12%）、描边（40%），各有令牌。标签一律「点或图标 + 字」。
7. 页头一行：标题在左、操作在右。说明最多一行，长说明收进 ⓘ。
8. 控件高：桌面标准 32px、紧凑 28px（`h-control`），手机至少 40px。手机上输入框字号 16px。

## 二、令牌三层

| 层 | 是什么 | 谁能用 |
|---|---|---|
| 主题基色 | 每套主题 13 个种子基色（`--bg`、`--fg`、`--brand`、7 个状态色……），8 套主题色 × 亮暗 = 16 套；种子在 `src/theme/palettes.ts`，校准值由脚本算进 `palettes.generated.css` | 只有 `app.css` 的派生规则 |
| 语义令牌 | 本节下面的颜色、字号、圆角、阴影、动效（`app.css` 第一个 `@theme`） | 页面和组件 |
| 版式常量 | 某一页要的专用尺寸（`app.css` 第二个 `@theme`「版式常量」，如 `h-topbar`、`max-w-cockpit`、只给任务页用的 `max-w-task-table`） | 只在写明的那一页用 |

`@theme` 里有 `--color-*: initial`：Tailwind 默认色板（`red-500`、`white`、`black`……）整个不生成，写了也不生效。

### 2.1 颜色

| 类名 | 用途 |
|---|---|
| `background` | 页面底 |
| `panel` | 侧栏、顶栏 |
| `card` | 区块、卡片 |
| `popover` | 浮层、菜单、对话框 |
| `muted` | 弱底：表头、展开区、代码块 |
| `accent` | 悬停底（前景 7%） |
| `selected` | 选中行底（前景 10%） |
| `foreground` | 主要文字 |
| `muted-foreground` | 次要文字。每套主题按 `--muted-ink` 校准，在 background、card、popover、muted、panel 上都 ≥4.5:1 |
| `border` | 分隔线（装饰，不要求对比度） |
| `border-strong` | 悬停、强调的边 |
| `input` | 控件边框。按 `--input-ink` 校准，对 card ≥3:1（WCAG 1.4.11） |
| `ring` | 聚焦圈。按 `--ring-ink` 校准，对 background ≥3:1 |
| `brand` / `brand-foreground` | 品牌色，只用于主按钮、选中导航、链接 |
| `destructive` / `destructive-foreground` | 危险按钮。底是状态红的墨色，字每套主题单配，≥4.5:1 |
| `scrim` | 对话框、抽屉后面的遮罩（亮 50% 黑、暗 60% 黑） |
| `st-{tone}` | 状态实色：点、条、图标 |
| `ink-{tone}` | 状态文字（≥4.5:1） |
| `st-{tone}-soft` | 状态淡底（实色 12%） |
| `st-{tone}-line` | 状态描边（实色 40%） |

tone 有八个：run、wait、human、stall、fail、done、stop、doubt。

`faint` 已删除。装饰性的图标也用 `muted-foreground`。

### 2.2 字号

参照苹果 macOS HIG 的字阶（Body 13/16、Callout 12/15、Title 3 15/20、Title 2 17/22、Title 1 22/26、Large Title 26/32，来源 developer.apple.com/design/human-interface-guidelines/typography 的 macOS built-in text styles，2026-10-11 核对）。桌面（md，48rem 起）用 macOS 档，手机（<48rem）保持原来的值、正文 14 起，可点区 40 不变。两组值都在 `app.css`：手机在第一个 `@theme`，桌面在紧随其后的 `@media (width >= 48rem)` 里覆盖 `--text-*`，页面代码不分宽度（#1882）。

| 类名 | 桌面（≥48rem） | 手机（<48rem） | 字重 | 用途 |
|---|---|---|---|---|
| `text-meta` | 12 / 16 | 12 / 16 | 400，可 500 | 时间戳、表头、计数、标签里的字、辅助说明（中文最小 12，两组一样） |
| `text-body` | 13 / 16 | 14 / 20 | 400，可 500 | 默认：列表行、表格、正文、按钮、输入、菜单 |
| `text-heading` | 15 / 20 | 16 / 24 | 600 | 区块、卡片、抽屉、对话框标题（对 Title 3） |
| `text-title` | 22 / 28 | 20 / 28 | 600，字距 -0.01em | 页面标题（对 Title 1） |
| `text-display` | 26 / 32 | 28 / 32 | 600 | 指标大数字（配 tabular-nums；对 Large Title） |
| `text-canvas` | 11 / 14 | 11 / 14 | 400 / 500 | 只在 `components/home/board/` 的画布里用 |

行高、字重绑在字号上，不另写 `leading-数字`。字重只用 `font-normal`、`font-medium`、`font-semibold`。
旧名 `text-micro`、`caption`、`sub`、`label`、`strong`、`stat-num`、`stat` 已在收口片（#1855）从 `app.css` 删除。

### 2.3 间距

内外边距、`gap`、`space` 只用这些档：`0`、`px`、`0.5`、`1`、`1.5`、`2`、`2.5`、`3`、`4`、`5`、`6`、`8`、`10`、`12`、`16`。
宽高（`h-*`、`w-*`、`size-*`）不限档，但不许写任意值。

### 2.4 圆角

| 类名 | 值 | 用途 |
|---|---|---|
| `rounded-sm` | 4px | `StatusBadge`、`Tag`（同一套外形，见「StatusBadge 与 Tag 的分工」）、提交号小块、探针格 |
| `rounded-md` | 6px | 按钮、输入、下拉、菜单项、分段筛选 |
| `rounded-lg` | 10px | 区块、卡片、弹层、对话框、抽屉 |
| `rounded-full` | — | 圆点、头像、计数角标（不画文字标签） |

### 2.5 阴影

| 类名 | 用途 |
|---|---|
| `shadow-xs` | 描边按钮、输入 |
| `shadow-card` | 区块、卡片（亮：只有一根下边线，没有模糊投影；暗：无） |
| `shadow-overlay` | 浮层、菜单、下拉、提示、画布浮动工具条 |
| `shadow-modal` | 对话框、抽屉 |
| `shadow-row-selected`、`shadow-brand-ring`、`shadow-done-pop` | 特效：选中行竖线、额度热、完成一闪 |

### 2.6 动效

时长只用 `duration-100`（悬停变色）、`duration-200`（展开收起）、`duration-300`（抽屉进出）。
缓动：`ease-out`（进入、展开），`ease-in-out`（来回切换）。
系统设置或设置页打开「减少动效」时，全部停下。

### 2.7 组件令牌和密度

学 Ant Design 的组件令牌和紧凑算法（方案第十三节）：只给会随密度变的五个尺寸起名，切一组值整站一起变。

| 类名 | 是什么 | 标准 | 紧凑 | 用在 |
|---|---|---|---|---|
| `h-control`（`size-control`、`min-h-control`） | 控件高 | 32 | 28 | 按钮、输入、下拉、开关组、筛选标签 |
| `h-row`（`min-h-row`、`size-row`） | 行高 | 40 | 32 | 列表行、大号按钮 |
| `p-section`（`px-`、`py-`、`mb-`） | 区块内边距 | 16 | 12 | 区块的页头和正文、空状态、展开明细 |
| `gap-section-gap` | 区块间距 | 24 | 16 | 页头和内容之间、两栏区块之间（lg 起） |
| `gap-stack`（`py-stack`、`px-stack`） | 区块内间距 | 12 | 8 | 页头、区块页头、行内元素之间、横幅左右 |

- 值在 `app.css` 里的密度变量块，`<html data-density="comfortable|compact">` 切换；`ThemePref.density` 存在浏览器本地，默认标准，认不出的值回到标准。设置页「外观」有「密度：标准 / 紧凑」，陈列页 `/_design` 顶上也有。
- 紧凑只在桌面（md，48rem 起）生效。手机上不变，所以 390 宽两种密度完全一样，40 的可点区（#1820）照旧。
- 字号不跟着缩：中文最小 12，紧凑只收框的高度和留白。
- 任何一棵子树挂 `data-density` 都按它自己的来，嵌套的 `data-palette` 不会把密度重置回标准。
- 只许 `components/layout/`、`components/ui/` 用（lint-design R10）。页面要尺寸就用版式组件，不自己写这五个类。
- 不随密度变的尺寸（标签、图标、徽标、小号按钮 `xs`）不起令牌：小号按钮最矮 24px，是可点区的下限，紧凑也不再缩。
- 两个比例：列表行上下内边距 = (`h-row` − 一行正文 20px，桌面正文 16px 时由 `min-h-row` 兜底) / 2，键值行 = `h-row` / 5，筛选标签和 `sm` 号控件比 `h-control` 少 4px。都写成 `calc(var(--spacing-…) …)`，只在 layout、ui 里。

## 三、版式组件（片 2 起）

组件放 `packages/web/src/components/layout/`。页面拼组件，不手写卡片、标签、空状态。
页面只传内容和语义（`tone`、`variant`）。`className` 只留给布局：宽度、栅格位置、外边距。
状态类组件渲染 `data-tone`。单测断言 `data-tone`，不断言类名。

| 组件 | 替掉的手写 |
|---|---|
| `Page` | 页头：标题左、操作右，刷新在固定槽位（见下面「页头」） |
| `Section`、`SectionGrid` | `Panel` 和手写的 `rounded-* border bg-card` |
| `List`、`ListRow` | 各自定行高的 `divide-y` 列表、`ExpandRow` |
| `KeyValue` | 四种 `<dl>` 排法 |
| `StatusBadge`、`Tag` | `StatusChip` 和页里手写的状态小块 |
| `EmptyState` | `Empty` 和手写的虚线框 |
| `Toolbar`、`FilterTabs`、`FilterTabGroups`、`SearchInput`、`NativeSelect` | 四种筛选条、手写的分组筛选和悬着的组说明、手写带图标的搜索框、原生 `<select>` |
| `Notice` | 手写的出错、提醒横幅 |
| `RowFrame`（`list.tsx`） | 自己管 `li` 的列表（拖动排序）里手写的行高、内边距 |
| `RowMenu`、`RowMenuItem`、`RowMenuRadioItem`、`RowMenuLabel`（`row-menu.tsx`） | 一行里并排的四五个小按钮、行内的下拉 |

### 行：一个主信息、一个状态，次要操作收进「⋯」（#1914，路由页样板）

参照 macOS 系统设置、Linear 列表行、Vercel 设置页：每行只有一个主信息和一个状态，层级靠字重和灰度，不靠边框和色块。

- 一行从左到右：（拖动柄）序号或状态点、名字加一行灰字小字、一个状态、开关、行尾「⋯」。别的都不进行里。
- 状态只放一个：有状态色的用 `StatusBadge`（行里挤的时候 `variant="dot"`，点加字、没有底），没有状态色的用 `Tag`。
- 偶尔才动的操作（挪位置、档位、移出、整池暂停……）收进 `RowMenu`。鼠标设备上「⋯」和拖动柄平时藏着，悬停这一行、键盘焦点进到这一行、菜单开着时才露出；触屏一直显示。菜单项手机上至少 40 高。键盘快捷键（Alt+方向键挪位置）照旧挂在拖动柄上，写在柄的悬停提示和页头 ⓘ 里。
- 行用 `RowFrame`（或 `ListRow`）：行高、内边距取 `h-row`、`p-section`，带 `group/row` 给悬停露出用；拖动柄浮在行左边的留白里，不占一列。
- 行和行之间不画分隔线，悬停 `bg-accent`、选中 `bg-selected` 加左边竖线。关着、被跳过的行只把名字那块降对比度（`opacity-60`），不整行换灰底。
- 一页最该看的那一句（路由页：这个用途现在实际派给谁）做成区块上面的标题块：名字 `text-heading`，结论一句 `text-body font-medium`，细节一行 `text-meta` 灰字。
- 同一类的几组次级筛选用 `FilterTabGroups`：组间一道细竖线，后一组前面写组头小标题，组尾可以带一句灰字；不在筛选条上面悬一行小字。

### StatusBadge 与 Tag 的分工（#1910）

- `StatusBadge`：有状态色的（在跑、卡住、失败、已完成、已关……），点或图标加字，意思靠字传。
- `Tag`：分类、来源、套餐、提交号这类没有状态色的；`tone` 只是着色，不表示进度或好坏。
- 两者外形同一套：`components/layout/tone.ts` 的 `badgeShape`（`h-5`、`px-1.5`、`text-meta font-medium`、`rounded-sm`），改一处两边一起变。不再有全圆胶囊文字标签；页里不手写 `rounded-full` 加字的小块。
- 一屏里圆角就三档：按钮、输入 `rounded-md`；标签和状态 `rounded-sm`；卡片 `rounded-lg`。

### 筛选条和保存钮（#1904）

- 筛选一律用 `FilterTabs`：同一页的主筛选用默认（灰底轨道），同一页再有一组次级筛选用 `variant="secondary"`（没有轨道），两组不用同一个样子。选中态用 `bg-selected`，不用白底卡片反显。
- 窄屏横向滑动，还有内容没滑出来的那一端渐隐；页签模式支持左右方向键、Home、End，`idPrefix` 给页签起 id。
- 分组说明（「不是流程里的一段」这类）写在组头上，不当选项放进筛选条。
- 保存按钮用 `SaveButton`：能存是 `brand` 实色，不能存（没改动、正在存）是灰底灰字的禁用样子。
- 状态字（在跑、关着、开着、已关）经 `StatusBadge`（点加字），没有状态色的标签才用 `Tag`；lint-design R11 拦裸文字。
- 通知卡正文默认两行，点一下展开；主操作带字，手机上也不退成无字图标。

### 页头（`Page`，#1897）

- 标题行：标题在左（后面跟 ⓘ），操作和刷新在右，同一行垂直居中；刷新是标题行右侧的固定槽位（`refresh` 属性），页面不自己摆 `RefreshBar`。
- 说明（`description`）最多一行，写在标题行下面；字符串超过 50 个字自动收进 ⓘ。长说明用 `detail` 传，任何宽度都在 ⓘ 里。手机上说明也收进 ⓘ，`keepDescription` 才例外（任务页的状态行这种关键信息）。
- 一页只有一个说明位：说明写这页管什么，不写「怎么用」「点这里」这种占位。
- 所有页同一最大宽（`max-w-cockpit`），页面不自己限宽、不再有窄栏。
- 手机上刷新是不带框的图标按钮（`ghost`），比标题弱；桌面是带字的描边按钮。
- 页头右边已经放了一句汇总的页（主页、路由页）刷新用 `refresh.variant = 'dot'`：只一个图标钮，最后更新时间在悬停和读屏里，数据旧了才写「数据有点旧 / 数据已过期」。
- 页头右边的汇总只写一句（「4 个派得出去 · 1 个不知道」），不排一串状态胶囊；坏的、不知道的数是 0 就不写，不画红。

## 四、检查规则（lint-design）

扫 `packages/web/src` 下非测试的 `.ts`、`.tsx`：取出所有字符串和模板串的静态段，按空白切成类名，去掉变体前缀（`md:`、`hover:`、`data-[…]:`）后逐条判。`.css` 只判 R0。
报错写清文件、行号、类名、该换成什么、本文第几节。

| 规则 | 拦 | 对 | 错 |
|---|---|---|---|
| R0 任意值 | `xxx-[13px]` 这种写死的尺寸 | `max-w-cockpit`、`shadow-[0_1px_0_var(--border)]` | `max-w-[380px]` |
| R1 颜色 | 默认色板、`white`、`black`；语义色上加 `/N` 透明度 | `bg-st-fail-soft`、`border-st-fail-line`、`bg-scrim` | `bg-st-fail/10`、`text-white`、`bg-black/50` |
| R2 字号 | 六档以外的字号；画布外用 `text-canvas` | `text-meta`、`text-body` | `text-xs`、`text-caption`、`text-sm` |
| R3 字重 | `font-bold`、`font-light` 等 | `font-semibold` | `font-bold` |
| R4 间距 | 不在 2.3 节档位里的 p、m、gap、space | `px-4 py-2.5` | `p-3.5`、`pt-7` |
| R5 圆角 | `rounded`、`rounded-xs`、`rounded-xl`、`rounded-2xl`、`rounded-2` | `rounded-lg` | `rounded-xl` |
| R6 阴影 | `shadow`、`shadow-sm/md/lg/xl/2xl`、已删除的旧名 `shadow-card-edge` | `shadow-card`、`shadow-overlay` | `shadow-lg` |
| R7 行高字距 | 数字行高 `leading-4/5/7`、`leading-loose`；所有 `tracking-*` | `leading-relaxed` | `leading-5`、`tracking-tight` |
| R8 手写版式 | 页面和业务组件里，同一串里有 `border` 和 `bg-card`（手写卡片）、有 `border-dashed` 和 `text-center`（手写空状态） | `<Section>`、`<EmptyState>` | `"rounded-lg border bg-card p-4"` |
| R9 原生控件 | 页面和业务组件里直接写 `<select>`、旁边带图标的 `<input>` / `<Input>` | `<NativeSelect>`、`<SearchInput>` | `<select value={repo}>` |
| R10 组件令牌 | 页面和业务组件里写组件令牌表里的五个令牌类（`h-control`、`h-row`、`p-section`、`gap-section-gap`、`gap-stack` 及它们的 `min-h-`、`px-`、`mb-` 等写法），或在任意值里引 `var(--spacing-control)` 这类 | 用 `<Section>`、`<List>`、`<Button>` | `"h-control p-section"` |
| R11 状态字裸文字 | JSX 正文里整段就是「在跑」「关着」「开着」「已关」（`<Tag>关着</Tag>`、`<span>在跑</span>`）；状态要点加字，经 `StatusBadge`，没有状态色的标签才用 `Tag`（#1904） | `<StatusBadge tone="stop" label="关着" />` | `<Tag>关着</Tag>` |

R8、R9、R10 不管 `components/ui/` 和 `components/layout/`：那里本来就是写这些的地方。
白名单在 `lint-design.ts` 的 `ALLOWLIST`，每一项写理由。现在只有三项：引 CSS 变量的任意值；`components/ui/` 里的聚焦圈透明度；`components/ui/` 里按钮的悬停透明度。

命令（在 `packages/web` 下）：

```
node scripts/lint-design.ts             严格检查，有一条违规就退出 1
node scripts/lint-design.ts --report    每条规则的总数、违规最多的前 20 个文件
node scripts/lint-design.ts --list      列出每一处
```

## 五、严格模式

检查是严格模式（#1855 收口）：`packages/web/src` 下一条违规都不许有，新文件、老文件一样。没有旧账清单，也没有按文件冻结的例外；唯一的例外是上一节说的白名单，每项写理由。

- `src/test/lint-design.test.ts` 里有一条用例扫整个 `src`，有一处违规就红。

## 六、对比度闸

`packages/web/src/lib/contrast.test.ts` 把 16 套主题逐套算一遍（WCAG 2.2 AA）：

- 状态墨色 `ink-{tone}` 在各种底和同色淡底上 ≥4.5:1；
- `muted-foreground` 在 background、card、popover、muted、panel 上 ≥4.5:1；
- `input` 对 card、`ring` 对 background ≥3:1；
- `destructive-foreground` 对 `destructive` ≥4.5:1。

每组都有一条故意造红的用例。校准值不手写：由生成脚本算（见下一节），测试读的是生成文件。

### 怎么加一套主题

主题只写种子，校准值由脚本算（学 Ant Design 的「种子 + 算法派生」，依据见 `specs/1844-驾驶舱设计规范/方案.md` 第十三节）。

1. 在 `packages/web/src/theme/palettes.ts` 的 `PALETTE_SEEDS` 里加两条（深、浅各一条）：`{ id, mode, seeds }`。`seeds` 只写 13 个 `#rrggbb` 基色：`bg`、`panel`、`surface`、`elev`、`fg`、`brand`，加七个状态色 `run`、`wait`、`human`、`stall`、`fail`、`done`、`stop`。这里不写任何百分比。
2. 在 `src/lib/theme.ts` 的 `PaletteId` 和 `PALETTES` 里登记 id、名字和一句话介绍。
3. 跑 `pnpm --dir packages/web gen:palettes`。脚本对每个校准量用二分法找「最少要混多少前景色」，在要求的所有底色上过线（文字 4.5:1，控件边框和聚焦圈 3:1），再多留 0.1 对比度的余量，写进 `src/theme/palettes.generated.css`。`--brand-foreground`、`--destructive-foreground` 在本套的页面底和主要文字色里取对比度高的。
4. 提交种子表和生成文件。不要手改生成文件：`src/theme/palettes.test.ts` 在内存里重新生成一遍，和提交的文件有一个字不同就红。
5. 脚本报「过不了线，换种子」，说明这套的前景色和底色本身对不上，改种子，不要去降门槛。

## 七、截图怎么交

改界面的 PR 带改前（主线）、改后两组截图。用 `packages/web/scripts/shots.ts`，它会起 `dev:mock`（假数据，不连后端）：

```
node scripts/shots.ts before                      12 页 × 1920/1366/390 × 亮暗
node scripts/shots.ts after --widths 1366 --pages home,tasks --modes light
```

图存到仓根 `_tmp/shots/<标签>/<页>-<宽>-<亮暗>.png`。
全局改动（令牌、`ui/`、外壳）要贴全部 12 页的改前改后图，至少 1366 宽亮暗各一张。
不做像素对比闸：迁移期每片本来就要变样子。
