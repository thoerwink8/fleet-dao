## 决定

1. **接口**：reclaude 有读拼车情况的接口——仓里早在用（`GET /api/v1/carpool/quota`、`GET /api/v1/orgs`，读取器 `packages/adapters/src/quota/readers/reclaude.ts`；recorded `docs/design.md:505`、`docs/reference/quota.md`）。**不是**新东西，方案 1.3 节写的就是在用的这套。官方文档没有 API 页（`llms.txt` 只列导览），这两个口是网页「设置 → API Key」那条路留给的。
2. **设备 4 台已满、无空位**：**mac、本机、本机 WSL、法国**（公司设备已撤）。→ **选项 E 不做**（E 要法国占 2 台、得先撤一台）；**切号走选项 A（一台设备、聪明切号）**。
3. **WSL 和法国共用同一套流程**，WSL 只是临时测试环境、后续不会用太多。
4. **额度机制的理解**（按他说的）：拼车 `$80/5h` 是 reclaude 加的**额外**闸，为的是防 1 人多用；底下真正的限制是官方账号的 5h / 7d / Fable 窗口。「车上几个人、别人占了多少」**不用管**，本人被拒就是用到头了。所以**尽可能用拼车额度**、越早用完越好（早用完说明我们用了、别人没用）。
5. **派活方向**：**独享不派新活、老活干完；新活直接走拼车**；拼车用到被拒才切独享。
6. **留量做成全渠道配置项**（不只独享）：每个渠道配一个「最多用到这里」的线，**到了配置额度这条渠道就不能用了**；由用户在驾驶舱配。→ 方案 4.8 改写。
7. **法国和 WSL 不是一台设备、互不影响**：可以一台在拼车、一台在独享（他明确说「你理解错了」——v2 原稿写的「只法国能切独享」作废）。→ 方案 4.7 改写。
8. **派活优先级由配置项决定**，关键看模型优先级；**分类可再细分**（按任务类型），**每个分类没单独设置就走总配置**（他问「对吗」→ 对，就这么定）。
9. **切回拼车的宽限 G = 10 分钟**（「按你推荐」）。
