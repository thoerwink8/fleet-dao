## 决定

1. 报进度：开头一句最要紧的变化。
2. 「要你拍的」在前，编号、一件一行：事、定什么、推荐哪个、为什么。没有就写不用我定。只有人闸四类进这里。

4. 表后写上次之后做完的（带 PR 号），再列排队的。
5. 工人只读交代、不读通用段。派脱离会话的工人时，交代里写上这一条。
