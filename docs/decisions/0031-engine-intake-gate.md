## 为什么停（日志里查到的）

- #1186：引擎的 Grok 写了 28 分钟、用约 35 万 token，推送被拒。改动碰了 `.github/workflows/`，而干活的机器人故意没有 workflows 写权限（给了它就能改 CI）。这是设计，重试没用。
- #1182：`pr:open --new-issue` 和 PR #1183 同时开出这张单，没贴「本机做」，引擎 40 秒后拉走并行做同一件事；#1183 先合，引擎推送前并主线，在同样的文件上冲突，停住。单关了，任务还挂着。
- 共同根子：拉单门只看里程碑和接活开关，没有判这张单是不是引擎能做、该不该引擎做。

## 结论

1. **拉单门加判断（#1194、#1197）**：要改 `.github/workflows/` 的单不拉；已被开着的 PR 引用的单不拉。不拉时贴「本机做」并留一句话；读不到就报「没查成」，不当成没有。
2. **`pr:open --new-issue` 开的单自动贴「本机做」（#1199）**：随 PR 开出的单天然是「已有人在做」，不靠人记得加 `--local`。
3. **单关了就撤掉卡住的任务（#1198）**：对账发现单已关而任务还在，发放弃信号。
4. 选项 B 和 C 不做。
