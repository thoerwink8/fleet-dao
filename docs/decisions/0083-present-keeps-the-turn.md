## 决定

1. 人在场（没开无人值守）：还有子代理或下一刀，这一轮不收。新话在下一刀之前先回。活没干完不许写成收工。子代理放后台，不杀。单次前台等待不超过 60 秒。
2. 开了无人值守，才由收尾钩子把这一轮挂住。这一条原来就这样，不改闸门。
3. 删掉引导中继：不再读 diag 的 `turn.steer`，不再起 ui-cli，不再为了转原文拒工具调用或挡收尾。`~/.fleet-dao/steer-shown/` 只留给开会话对账读旧记录。
4. 流程钩子（开会话、主对话这两条、收尾、落盘）只登记在 fleet-dao 仓的 `.claude/settings.json`。用户级只留拦密钥的调工具前钩子。同步摘掉标准里不再列出的登记。不另做合并后的 git 钩子。
5. 引擎的无头会话读得到项目级设置。起会话时设 `FLEET_HEADLESS=1`，上面四条流程钩子和引导钩子直接退出。拦密钥仍走引擎自己带的 `--settings`。
6. 别的仓不装这些钩子。要需求四节、方案、设计的写法，把 `docs/writing.md` 整份抄进那个仓自己的 `AGENTS.md`。

## 没做的

- 不改 Mirasim 的发送键。有后台任务时它只剩「引导」，引导是排队。
- 不把通用段从各家全局说明里拿掉。别的 fleet 仓（daihuo-workbench、humming-sauteeing-wreath）没有自己的项目钩子文件，下次同步摘掉用户级之后，它们不再跑开会话、收尾、落盘。要这些，得在那个仓自己的项目设置里登记。
- 权限那一层仍是用户级，这次不动。
