# 0030 无人值守、过夜也用 Agent 子代理，不再脱离会话（创始人 2026-10-07 约 14:35 选定）

- 日期：2026-10-07（北京时间约 14:35）

- 状态：采纳
- 关联：替代 0024 里「脱离的工人只留无人值守、过夜、超 40 分钟」的例外，和 0026、0028 里「活仍由脱离会话的工人干」那一层；0024 的「默认用子代理」、0025 的子代理一道、0028 的「这一轮不结束」都不动。

## 原话

```
不应该脱离会话，是哪里的规则，改回来？
```

## 结论

1. **无人值守、过夜也用 Agent 子代理，不脱离会话。** 子代理用什么模型照决定 [0034](0034-subagent-by-cost-effectiveness.md)（原写的 `model: "sonnet"` 已被它取代；无人值守的监控也改成脚本为主，见 0034 第 9 条）。 步骤照旧：先 `unattended.mjs on`，这一轮不结束，等子代理的完成通知，有进展记进度、汇报，从队列头派下一件。
2. **脱离会话的工人只在创始人明说要脱离时用。** `worker.mjs` 和 `--detached "<理由>"` 的闸留着，不删。
3. 0024 当时不全禁，理由是「子代理活在这一轮里，轮次结束就死」。0028 起无人值守的会话这一轮不结束，这个理由已经不成立。
