# 0120 拼车 5 小时窗口怎么排：工作日上班钉 3 个窗口，下班和周末连着跑，空档走独享

- 索引状态：生效
- 日期：2026-10-24（北京时间）
- 谁拍的：创始人 2026-10-24 在讨论稿 #3687 上拍（原话在私有处）。
- 状态：采纳，引入它的 PR 合并即生效；实现另拆单。
- 关联：`specs/3687-拼车窗口与额度续跑/讨论稿.md`；`docs/reference/quota.md`（Q6、Q27）；`packages/engine/src/real/org-plan.ts`（切号）；决定 0018。

## 背景

拼车额度 5 小时 80 美元，reclaude 账号级共用（本机、其他电脑、法国引擎同一份）。窗口在第一次用时开始算整 5 小时，24 不是 5 的整数倍，所以"每天同一钟点清零"和"一个接一个不留空"不能同时要。10-20 到 10-24 实测 20 个窗口没有一个用满，平均每窗 25.8 美元。

创始人的核心诉求分两段：
- 上班（周一到周五 08:30–18:00）：碰到的窗口越多越好，而且每段都要来得及用满。
- 下班（工作日晚上、夜里、周末）：不数窗口，只求任务一直往前跑。

## 决定

1. **工作日上班钉 3 个窗口，清零在 10:30 和 15:30**。上班这 9.5 小时最多碰到 3 个窗口（两次清零至少隔 5 小时，放不下第三次），三段分别是 2 小时、5 小时、2.5 小时。不往前钉到 09:00 这类：第一段太短，用不满 80 美元。
2. **一条规则**：拼车一清零就马上点着下一个窗口，只有一种情况例外——点了会盖住下一个工作日 05:30 那一枪的，就不点，等到 05:30 再点。
   - 工作日：05:30 → 10:30 → 15:30 → 20:30 → 01:30，01:30–05:30 不点拼车。
   - 周末：周五 20:30 起一个接一个不停，到周一 03:30；03:30–05:30 不点拼车。
3. **拼车空着的这段，任务走独享接着跑**，不让任务停。本机和法国引擎都守这条：空档里谁碰拼车，周一到周五的钉子就松了。
   - 法国：05:30 切回拼车。
   - 本机：05:30 只打一枪探针点着窗口（打之前切到拼车，打完立刻切回独享），本机任务留在独享，08:30 上班才切回拼车。不然夜里没跑完的任务会把上班第一个窗口先吃掉一块。
   - 另外几台设备（两台 Windows、一台 Mac）夜里不跑任务，不装这套。
4. **本机探针和切号走 Windows 任务计划程序**，每分钟跑一个本机小脚本，到点才打探针（`reclaude -p` 最小请求）、才切号。不用桌面端定时任务：它会固定延后几分钟，一条规则只能有一个分钟数；而且它一跑就会发模型请求，切号必须抢在任何请求之前。桌面端只管续跑（给停下的会话发「继续」）。
5. **到点续跑**：任务因额度或限流停下（`StopFailure` 钩子 `quota-stop.mjs` 记一笔），桌面端定时任务「续跑巡检」每 30 分钟跑 `quota-resume.mjs due`：限流停 5 分钟后、额度停下后拼车开了新窗口或本机已挂独享或已过 5 小时，就往原会话发一句"继续"，带原上下文接着跑，不开新会话。创始人 2026-10-24 定：额度和限流都续，不等抓报错原文。停下后人已经发过消息的、停了超过 24 小时的不续。
6. **本机探针不依赖法国**：法国先用了就是它点着的，本机这一枪白打一次小请求，不算错。本机用 reclaude API Key 读真实清零时刻，被顶偏了下一枪按真实时刻纠回。

## 没做的

- 节假日日历：先不做，以后加一张表、当周末处理。
- 独享封号期间（只剩拼车）的排法和法国让不让出拼车：另在讨论稿 #3687 第五节讨论。
