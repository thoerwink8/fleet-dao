- 谁拍的：创始人
- 状态：实现已由 PR #614 合并（主线 `4de88172`），四平台 CI 通过；本机自动迁移已安排，等待在途回合空闲；真实请求额度与用户 Mac GUI 尚未验收
- 关联：`docs/mirasim-routing-and-macos-proposal.md`、调研 PR #573 / #579

## 原话

> 同意，开始实现，然后要有办法能达到实现后，一条命令或者不用命令，就能老机制直接变新机制

## 决定

1. Windows/macOS 的 Mirasim 自有 / 平台选择在下一回合生效，不打断当前回合、不重启其他会话；自有仍经 reclaude，平台保留 Mirasim 的注入与中继。
2. 读取错误、身份歧义不能被当作自有；状态和真实请求来源要能验证。
3. Linux 法国维持直接 reclaude 自有、无头 Mirasim cloud 两个明确入口，渠道切换和任务接续由 Fleet 控制；不复制桌面的混合来源切换机制。
4. 旧安装可以用一条命令迁移：识别旧命令、检查在途回合、验证新版本、空闲时替换、回读确认；保留旧配置与可撤回版本，不删除用户会话或账号数据。
5. 目标 Mac 不要求人手安装 Go；同一套源代码覆盖两种 Mac 架构。程序升级与运行验收不得只看能编译。

## 替代与边界

本记录将调研文档的建议变成已获同意的实施范围，替代其中「尚未同意、只调研」的状态描述。旧 ai-gateway-stack 一次启动判路的机制由本次实现替代；原指南须同步更新。未改变全局的 Claude 启动规则、账号切换禁令、法国引擎关闭状态或按版本确认发布的约定。
