## 决定

1. **坑：别名 `haiku` 在本机指向 Haiku 4.5，不是 5.5。** Agent 工具的 `model: "haiku"` 派出去的子代理自报 `claude-haiku-4-5-20251001`。要真 5.5，只认两条路：
   - Agent 工具写 `subagent_type: "haiku55"`，**不传 `model`**（传了会盖过定义文件）。它是自定义子代理文件 `~/.claude/agents/haiku55.md`，frontmatter 里 `model: claude-haiku-5-5`。这台没有这个文件、或会话里没出现 `haiku55` 这一类，就是没装上，不拿 `model: "haiku"` 顶。
   - 命令行 `claude -p --model claude-haiku-5-5 …`。
   派完核对实际 id：交代里要它汇报首行写自己的模型 id，不是 `claude-haiku-5-5` 就停，这次当没做、升到 Sonnet 重派。命令行返回的 `costUSD` 对 5.5 不准（它不认识 5.5 的价，实测报约 0.37 美元/次），不能当账；账按官方价（输入 0.10、输出 0.50 美元/百万 token）和实际 token 算。
2. **边界：不按活的名字，按「产出能被脚本或一条命令核对」。** 这些先给 Haiku 5.5：读码检索（回 `文件:行`）、日志和 CI 输出归纳（回证据行）、分类、准入和范围检查、评审初筛、规格明确的小函数（有测试判）、有失败测试的 bug 修复、按写全的规矩写任务书（配 `check-brief.mjs`）。核对的那条脚本或命令要在派之前就定好，写进交代。
3. **级联：先 Haiku，脚本核对不过就升 Sonnet，不在同档重试。** 小模型的失败信号不可靠，同一个错重试一次多半还是错。Sonnet、Opus 同档连着失败两次升一档（0034 第 3 条不变）。没有机器核对的仍给 Sonnet 或 Opus：开放式长链编码、改标准、架构方案、下结论的评审。官方基准里 Haiku 5.5 的长链命令行编码只有 Sonnet 5.5 的一半多（Terminal-Bench 4.0：39.2% 对 70.6%），我们的实测也没覆盖这一类，不外推。
4. **交代必须写全所有硬规矩。** 实测里没写明的细节它会漏（写任务书那题：我只写了 8 条硬规矩里的 4 条，它把函数名、事件名也用反引号括进「已知的模块」，会被引擎当路径判成跨模块）。派 Haiku 的交代把用到的每条硬规矩都写出来，并附上核对它的脚本或命令。
5. **先砍固定开销。** 每次子代理调用光起手的系统提示和工具说明就要写缓存约 2 万（精简配置：不加载 MCP、不加载技能）到 4.6 万 token（完整配置），这比模型差价更值得砍。`haiku55` 子代理用精简配置（定义里只给要用的工具、不带技能），交代里限制回合数和输出长度（一般 ≤10 行）。
6. **实测数据**（见下表）。样本小（每类 1~6 题，一个人出题、一台机器），只说明这些题，不当成 Haiku 5.5 的普遍成绩；新的活第一次给 Haiku 时照样配核对脚本，结果不对就照第 3 条升级，并把这次的结果补进本决定。
7. **引擎侧不在本决定里拍。** 驾驶舱的 Cursor 名册里已经有 Haiku 5.5 的变体路由（关着）。要不要把它配进哪个用途，由创始人在驾驶舱定，AI 不替他配（同决定 0033 的做法）。

## 实测数据

本仓真实任务，真 Haiku 5.5（自报 `claude-haiku-5-5`），每题答案都有脚本或人核对过。

| 题 | 结果 |
|---|---|
| 读码检索：找函数定义和所有非测试调用点 | 全对，位置和行号一致，主动区分了 import 和调用，注明没有 re-export |
| 读两份真实红灯 CI 日志，说根因 | 根因都找对，还多找出同一次里另一个真实失败；日志里没有的明说「不确定」 |
| 任务书准入检查（6 份单子，规矩 6 条） | 6/6 判对，证据到行号；同题 Haiku 4.5 只判对 4/6，还说「100% 把握」 |
| 评审初筛（合规、越界、越界+假密钥+删断言各 1 份） | 3/3 判对，三类违规全抓到 |
| 写小函数（规格明确，10 条隐藏测试） | 10/10 过（Haiku 4.5 也 10/10，这题区分不出） |
| 修植入的 bug（3 个，每个给一个失败的测试） | 3/3 修好、没动测试、没弄坏别的；回合数 5/5/14，Sonnet 5.5 是 6/7/6 |
| 写任务书（大单切一片，8 条硬规矩只写了 4 条） | 1 处不合格：把函数名、事件名括进「已知的模块」。规矩写明了就不会错 |

钱：同样 3 个修 bug 题，按官方价算 Haiku 5.5 约 0.032 美元、Sonnet 5.5 约 0.30 美元，实测约 9.4 倍（Haiku 回合和输出 token 更多，纸面价差约 20 倍）。
