## 决定

1. **派活默认用 Agent 工具起 Sonnet 子代理**（`model: "sonnet"`，可并行，仍守并发上限 4 和决定 0017）。创始人在 Mirasim 面板里看得见、能点进去插手。工作树照旧建在主检出的 `.claude/worktrees/` 下，交代照「写一份交代」的写法。
2. **脱离会话的工人（`worker.mjs start`）只留两种例外**：创始人说了无人值守、过夜、我不在；或活预计超过 40 分钟而他不在线。起它必须带 `--detached "<为什么必须脱离>"`，没带或理由太短就拒起（退出码 1），理由写进这个工人的 `meta.json`。闸放在动作必经的那一步，不靠记性。
3. **每次派活第一句话说清用的是子代理还是脱离的工人**，别让他猜。
4. **在跑的两个脱离工人**（gate-drop、unblock-1113）不动，做完为止；做完清掉。

## 为什么不是「完全不脱离」（指挥官的看法）

- 子代理活在聊天这一轮里，轮次结束或会话进程一重开就跟着死（2026-10-05 一天因此丢三次活）。长活要么脱离，要么让这一轮一直不结束。
- 这一轮不结束，他中途打的字（Mirasim 的「引导」）只在两次调用之间送到，一轮被打断、出错时会被 Mirasim 丢掉：2026-10-05 起 14 条引导丢 8 条。#1112 让开会话钩子在下一轮开头补上丢的话，把这个洞堵了大半，但不是零成本。
- 所以默认用子代理（看得见），把例外留给确实要过夜、要走开的长活，并用一道闸让例外有理由、有记录。
