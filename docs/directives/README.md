# 创始人引导

这里只收创始人讲的 AI 做法类引导（规矩、偏好、派活、用哪个模型/CLI，以后都管的），一条一个文件：`<月>/<编号>.md`。产品该长什么样的拍板进设计文档或决定，要去做的活开单，只这一次的不记，一时调整进 `docs/PROGRESS.md`「## 生效中的临时调整」（决定 0111）。旧文件里讲产品、要做的活的不改，以设计文档、决定和单为准。这里是记法的全文（仓根 `AGENTS.md` 只留指针），文件格式见 `packages/conventions/src/directives.ts` 开头。

- 记：先分拣，当场 `pnpm progress directive --kind <类>`（`ai|product|task|once|ops|discuss`，不带或认不出退出 1 并打出分拣表和判法；非 `ai` 不写文件、退出 0 并说去处；判法只在命令输出里，决定 0117）。`--kind ai` 不给原话就从本机 prompt-log 取本会话他最近一句、准确时间（+0800）和主人；取不到它会报错要你手填（`"原话" --at "时间"`）。记成 `docs/directives/<月>/<编号>.md`，自己开 PR 挂自动合并。
- 每条引导挂一张单（#2727）：`--issue <单号>` 挂已有的（要开着），不给就顺手开一张（杂项、挂当前版本、本机做）。文件里写一行 `- 单：#N`，**写进去之后不再改这个文件**。
- 办完：干活的 PR 写 `Closes #<单号>`（`pnpm pr:open --closes <单号>`），合并时单自动关；单关了就算办完。不用另开 PR 标状态，也没有认领、标已处理这两个子命令（#2727 删了）。不用办了的，直接关单并写明原因。
- 办没办完现查：`pnpm progress read --pending` 读本地 origin/main 上的引导文件，再用 gh 问挂的单开着没有（开着 = 没办完）；gh 读不到或没读全会报明确的失败（退出码 2），不当成没有。没有挂单的旧文件（#2727 以前记的）仍按文件里「状态：待处理」判，旧文件的「状态」「经过」行照读、不报错。没有没办完的引导时输出空、退出码 0。
- 接手先 `pnpm progress read`。进度流水 `pnpm progress note "一句话"` 仍记在置顶单 #1055（那里也是驾驶舱「要你拍」答案的收件箱）；收件箱里的一条要办，`pnpm progress directive --kind <类> --from-inbox <评论号> [--issue <单号>]`：`ai` 把它搬进仓（挂单同上），原评论改成「已迁」；其余类别不写文件，原评论改成「已处理」并写明记在哪。
- 开会话钩子：引导段每次开场同步现查（读本地 origin/main 加 gh，不用后台缓存），只叫主人那个会话办；凡是用后台缓存的行（整池暂停、绿了没挂的 PR、清工作树）都带「后台 N 分钟前」。挂过 24 小时本会话还没接的，钩子提醒指挥官自己接着办（不用认领、不进「要你拍的」、不用问创始人，决定 0097：交互会话只为掏新钱、删找不回的东西问他）。
- 10 位编号的是 2026-10-15 从置顶单 #1055 评论搬来的（编号沿用评论号），#1055 留作进度流水和驾驶舱答案的收件箱。

## 对外仓的原话

会话所在仓取 `INIT_CWD`，按 `repo-kind.mjs` 判为对外仓时，记 `--kind ai` 引导必须带 `--meaning "不带项目业务、人名、地址的意思"`；不给就退出 1。原话从本会话 prompt-log 取，手填用 `--stdin --at "时间"` 从标准输入读，不把正文放进命令行历史。收件箱 `--from-inbox` 也遵守这条。

公开引导文件和挂的单只记意思，文件另有 `- 原话：私有处 <id>`。原文先独占写进本机 `~/.fleet-dao/private/quotes/<id>.json`（私有目录，勿提交），再从标准输入经 SSH 调 `fleet-api quote put`；逐编号确认后才删待传文件。失败会明确说没传成并保留文件。自用仓记法不变，既有引导不搬。

用 `pnpm progress quotes:flush` 补传；开会话后台也补传一次，失败结果会在开场明确提醒。未传成退出 2，不回显原文或远端。库中原话只经私有管理命令 `fleet-api quote get <id>` / `fleet-api quote list --since <ISO时间>` 读取，输出不可粘进公开单或公开日志；同 id 异文拒绝，不覆盖。
