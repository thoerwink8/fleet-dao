# 创始人引导

创始人拍的板和中途的引导，一条一个文件：`<月>/<编号>.md`。命令和规矩见仓根 `AGENTS.md`「进度和单」，文件格式见 `packages/conventions/src/directives.ts` 开头。

- 记：`pnpm progress directive`（不给原话就从本机 prompt-log 取本会话他最近一句），自己开 PR 挂自动合并。
- 办完：在干活的工作树里 `pnpm progress done <编号>`，随那个 PR 提交；合进主线就算办完。
- 开会话钩子读 origin/main 上「状态：待处理」的文件，只叫主人那个会话办。
- 10 位编号的是 2026-10-15 从置顶单 #1055 评论搬来的（编号沿用评论号），#1055 留作进度流水和驾驶舱答案的收件箱。
