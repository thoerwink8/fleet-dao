- 记：先分拣，当场 `pnpm progress directive --kind <类> --meaning "<不带原话的意思>"`（`ai|product|task|once|ops|discuss`，不带或认不出退出 1 并打出分拣表和判法；非 `ai` 不记、退出 0 并说去处；判法只在命令输出里，决定 0117）。`--kind ai` 不给原话就从本机 prompt-log 取本会话他最近一句、准确时间（+0800）和主人；取不到它会报错要你手填（`"原话" --at "时间"`，主人认不出加 `--owner`）。经 `POST /api/nodes/notes` 写一条 `kind: directive` 的账本行：`text` 是原话，`meaning` 是意思（必给，单和周汇总在公开仓，只用它），`category` 是类，`owner`、`spokenAt` 是主人和他说话的时刻，`issue` 是挂的单。不写 `docs/directives/`、不开分支、不开 PR；账本写不成退出 2（没记成），不退回写文件。同一句话同一分钟重跑是重放（同一行，`created:false`）。
- 每条引导挂一张单：`--issue <单号>` 挂已有的（要开着），不给就顺手开一张（杂项、挂当前版本、本机做；标题和正文只用意思，不抄原话）。
- 办完：干活的 PR 写 `Closes #<单号>`（`pnpm pr:open --closes <单号>`），合并时单自动关；单关了就算办完。没有认领、标已处理这两个子命令（#2727 删了）。不用办了的，直接关单并写明原因。
- 办没办完现查：`pnpm progress read --pending` 增量读法国账本（本机 `~/.fleet-dao/ledger-inbox.json` 记读到哪一行，只请求新行），再用 gh 问挂的单开着没有（开着 = 没办完）；同时列本目录旧档案里挂的单还开着的。gh 或账本读不到、没读全会报明确的失败（退出码 2），不当成没有。没有没办完的引导时输出空、退出码 0。旧文件的「状态」「经过」行照读、不报错。

## 对外仓的原话

会话所在仓取 `INIT_CWD`，按 `repo-kind.mjs` 判为对外仓时，记 `--kind ai` 引导必须带 `--meaning "不带项目业务、人名、地址的意思"`；不给就退出 1。原话从本会话 prompt-log 取，手填用 `--stdin --at "时间"` 从标准输入读，不把正文放进命令行历史。收件箱 `--from-inbox` 也遵守这条。

对外仓的引导账本行里 `text` 也是意思（原文不进本仓的库，也不进任何公开处）；原文先独占写进本机 `~/.fleet-dao/private/quotes/<id>.json`（私有目录，勿提交），再从标准输入经 SSH 调 `fleet-api quote put`；逐编号确认后才删待传文件。失败会明确说没传成并保留文件。自用仓记法不变，既有引导不搬。

用 `pnpm progress quotes:flush` 补传；开会话后台也补传一次，失败结果会在开场明确提醒。未传成退出 2，不回显原文或远端。库中原话只经私有管理命令 `fleet-api quote get <id>` / `fleet-api quote list --since <ISO时间>` 读取，输出不可粘进公开单或公开日志；同 id 异文拒绝，不覆盖。
