## 对外仓的原话

会话所在仓取 `INIT_CWD`，按 `repo-kind.mjs` 判为对外仓时，记 `--kind ai` 引导必须带 `--meaning "不带项目业务、人名、地址的意思"`；不给就退出 1。原话从本会话 prompt-log 取，手填用 `--stdin --at "时间"` 从标准输入读，不把正文放进命令行历史。

对外仓的公开单里也只写意思。原文先独占写进本机 `~/.fleet-dao/private/quotes/<id>.json`（私有目录，勿提交；这是待传目录，和自用仓的 `directive-quotes/` 不是同一处），再从标准输入经 SSH 调 `fleet-api quote put`；逐编号确认后才删待传文件。失败会明确说没传成并保留文件。记进 GitHub 的那张单只带意思。

用 `pnpm progress quotes:flush` 补传；开会话后台也补传一次，失败结果会在开场明确提醒。未传成退出 2，不回显原文或远端。库中原话只经私有管理命令 `fleet-api quote get <id>` / `fleet-api quote list --since <ISO时间>` 读取，输出不可粘进公开单或公开日志；同 id 异文拒绝，不覆盖。
