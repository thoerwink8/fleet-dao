# 创始人引导

创始人拍的板和中途的引导，一条一个文件：`<月>/<编号>.md`。这里是记法的全文（仓根 `AGENTS.md` 只留指针），文件格式见 `packages/conventions/src/directives.ts` 开头。

- 记：当场 `pnpm progress directive`。不给原话就从本机 prompt-log 取本会话他最近一句、准确时间（+0800）和主人；取不到它会报错要你手填（`"原话" --at "时间"`）。记成 `docs/directives/<月>/<编号>.md`，自己开 PR 挂自动合并。
- 每条引导挂一张单（#2727）：`--issue <单号>` 挂已有的（要开着），不给就顺手开一张（杂项、挂当前版本、本机做）。文件里写一行 `- 单：#N`，**写进去之后不再改这个文件**。
- 办完：干活的 PR 写 `Closes #<单号>`（`pnpm pr:open --closes <单号>`），合并时单自动关；单关了就算办完。不用另开 PR 标状态，也没有认领、标已处理这两个子命令（#2727 删了）。不用办了的，直接关单并写明原因。
- 办没办完现查：`pnpm progress read --pending` 读本地 origin/main 上的引导文件，再用 gh 问挂的单开着没有（开着 = 没办完）；gh 读不到或没读全会报明确的失败（退出码 2），不当成没有。没有挂单的旧文件（#2727 以前记的）仍按文件里「状态：待处理」判，旧文件的「状态」「经过」行照读、不报错。没有没办完的引导时输出空、退出码 0。
- 接手先 `pnpm progress read`。进度流水 `pnpm progress note "一句话"` 仍记在置顶单 #1055（那里也是驾驶舱「要你拍」答案的收件箱）；收件箱里的一条要办，`pnpm progress directive --from-inbox <评论号> [--issue <单号>]` 把它搬进仓（挂单同上），原评论改成「已迁」。
- 开会话钩子：引导段每次开场同步现查（读本地 origin/main 加 gh，不用后台缓存），只叫主人那个会话办；凡是用后台缓存的行（整池暂停、绿了没挂的 PR、清工作树）都带「后台 N 分钟前」。挂过 24 小时本会话还没接的，钩子提醒指挥官自己接着办（不用认领、不进「要你拍的」、不用问创始人，决定 0097：交互会话只为掏新钱、删找不回的东西问他）。
- 10 位编号的是 2026-10-15 从置顶单 #1055 评论搬来的（编号沿用评论号），#1055 留作进度流水和驾驶舱答案的收件箱。
